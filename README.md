# 文档挖掘助手

面向审计资料分析与来源核验的前端原型、原前端参考代码和整体设计方案。

## 启动当前原型

```bash
python3 优化方案/交互原型/deploy/preview.py --host 127.0.0.1 --port 8080
```

访问 http://127.0.0.1:8080/#library 。当前原型为静态交互演示，真实业务服务接入边界见后端开发清单。

## 项目结构

- `优化方案/交互原型/dist/`：当前前端，资源版本20261024.80。
- `优化方案/交互原型/tests/`：浏览器回归脚本。
- `优化方案/交互原型/deploy/`：预览、部署及文件校验工具。
- `优化方案/交互原型/review/`：历次专项检查记录和截图。
- `优化方案/总体优化设计方案-20261025/`：整体设计、UI规范、模块对照、后端清单、验收及PDF/Word阅读版。
- `优化方案/UI界面规范/`：UI专项规范和历史修订。
- `前端代码/`：原系统源码摘录，供功能和接口核对。
- `界面截图/`、`会议纪要/`：项目原始参考资料。

从[总体方案入口](优化方案/总体优化设计方案-20261025/00-阅读入口.md)开始阅读。

原型、本地测试和方案资料一并归档；重复部署ZIP和展开的历史部署目录由.gitignore排除。
