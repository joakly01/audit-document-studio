# UI 还原核对记录

基准：已确认的《总体优化设计方案》及 `03-UI交互与开发规范.md`；原型静态资源 `20261024.80`。用户后续确认的文案和功能优先，不恢复已取消的入口。

## 本轮还原范围

1. 独立访问恢复原型的 192px 左侧导航和工具分组；嵌入模式继续隐藏应用导航。
2. 工具命令栏恢复 56px，标题、分析记录和主操作置于一行；取消新增的大段顶部说明与工作区外层卡片留白。
3. 通用三栏采用 320px 左右栏、紧凑分隔；信息提取保留独立栏宽。复杂工具继续两栏。
4. 输入与主按钮正文 16px，辅助/表头/状态不低于 14px，统一色值与控件尺寸。
5. 还原提示词的业务说明、来源和摘要；编辑窗口把可用高度分配给正文。
6. 所有弹窗限制在可视区域，标题和底部操作始终可达；重点检查低矮窗口、资料选择和长规则编辑。
7. 核对资料管理、模板、任务和各工具结果，保留专用布局、原文入口和全部业务操作。

实测基线：1366×768 下原型导航 192px、工具命令栏 56px、原文头部 44px。新 Vue 使用 56px 顶部导航，工具标题区约 79px，工作区再增加四周 12px 外边距；这会减少约 100px 的实际阅读高度。Element Plus 主控件字号仍为 14px，部分辅助字为 12–13px。

本轮采用恢复既有设计的做法，不新增业务步骤，不改变提交参数或历史配置。演示数据内容与原型不同，不能据此计算逐像素一致率；对布局、尺寸、样式和交互分别验证。

## 本轮核对结论（2026-10-28）

原 Vue 前端的业务页面已建立，但导航方向、工具标题区、栏宽、辅助字号、规则清单和弹窗高度与已确认原型有明显差异。本轮已修正这些共性问题，并逐页检查 11 个工具准备页、11 类结果、资料管理、模板、提示词与任务中心。

可离线打开 [原型 / 修正前 / 修正后截图对照](../review/ui-restore/对照查看.html)。截图已内嵌，支持切换页面、对照来源和放大查看。原型与前端的演示资料不同，因此不报告“像素还原百分比”。

### 关键修正

- 资料管理、提取模板、任务中心使用统一面板、表头、状态色、分页位置和紧凑命令区；核心操作直接呈现。提取模板恢复“使用模板”，载入字段时保留已选资料，替换已有字段前确认。
- 招投标检查方式以三个明确的模式卡片呈现，规则使用可搜索、分页的表格；合同规则也使用表格，风险点继续保留分类与筛选。项目添加入口位于资料栏标题处，统计固定在底部。
- 提示词显示来源和内容摘要；编辑弹窗优先给正文分配空间。1024×480 下正文约 277px，390×600 下约 363px；标题、取消、应用等操作可达。
- 资料管理预览恢复宽屏原文件 / 解析文本双栏；窄屏使用页签。工具内原文仍为单栏紧凑预览，不增加步骤，不恢复“收起原文”。
- 原文空态恢复居中引导；结果页减少外围留白，继续保留工具专用成果、来源、导出和再次分析。
- 手机目录把空间选择和查找合为一行；目录树至少可完整显示两行，文件表和弹窗底部操作仍可达。

### 独立复核发现并关闭的问题

1. **Office 阅读状态回退。** 宽窄模式切换触发重新加载，导致台账返回首张工作表第一页。改为保留预览 DOM 和当前工作簿，文件变化才重新加载。双工作表夹具先在旧产物复现失败，再验证新产物保留“核验明细”第 2 页且不重复下载。[失败证据](../review/ui-restore/office-state-before.json)、[修复后证据](../review/api-preview/report.json)。
2. **手机目录残行。** 目录控件挤占高度，资料管理 / 选择器的目录视口只剩 25px / 15px。修正后新增实际视口 ≥76px 的断言，通过界面回归；不是只判断整页无横向滚动。

## 差异与验证边界

- 最新用户确认优先。原型旧结果截图中的“本次配置 / 复制新建”等入口不会恢复；保留“再次分析”和三个任务文字操作。
- 图标与下拉使用统一组件库，部分轮廓和菜单外观不与原型自定义控件逐像素相同；布局、尺寸、动作和业务含义按当前规范实现。
- 原型演示资料与 Vue 演示资料不同。长目录、大量文件、超长提示词和真实审计成果仍需使用业务数据进行人工验收。可见文字对比度扫描只覆盖本轮捕获状态，不代表整站所有状态的无障碍认证。
- 原件测试使用有效 DOCX / XLSX 字节和本地 API 响应夹具；PDF 自动化只验证地址及页码绑定。真实后端、原生 PDF 渲染、权限和模型输出质量不在本轮视觉核对结论中。
- UI 核对完成时只更新了前端源码、构建与核对材料。随后按用户“更新服务器”的指令，于 2026-10-28 10:20 发布本轮修正；35 项部署检查及 67 项线上 UI 检查通过，详见 [部署记录](DEPLOYMENT.md)。提交状态以 Git 历史为准，未另外生成部署包。

复跑界面检查：`node tests/browser-ui-restore.mjs`；生成对照文件：`node tests/create-ui-comparison.mjs`。需要先启动 5173 演示服务；API 预览检查另需 4173 默认生产产物预览。
