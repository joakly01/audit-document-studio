# 资料模块实现与验证

对照 `优化方案/总体优化设计方案-20261025/03-UI交互与开发规范.md`，资料管理和选择器统一使用“当前目录”，包含空间和实际目录路径。目录树、分页、解析状态和关键词搜索通过 StudioService 获取数据，中文输入期间不触发 Enter 查询。

## 已实现

- 独立 ID 选集跨目录、跨页保留；表头仅操作本页。顶部提供全部页、仅保留本页、取消本范围选择。选择器另有清空全部，空确认支持清除单表角色。取消弹窗不发出确认，不修改调用方选集，关闭后旧异步选择结果不影响重新打开的弹窗。
- 已选资料弹窗支持搜索、分页和移除；移除不删除资料。进入分析和选择器确认均重新获取服务端文件状态/权限，变化后提示复核，避免静默提交失效资料。
- 上传清单支持文件和文件夹，展示文件名、相对路径、类型、大小和上传状态。界面传目标根目录和完整 relativePath，由服务适配层统一创建子目录并上传，避免重复嵌套；上传期间固定目标目录/空间。单文件限 100 MB，拒绝越界路径和空文件，同路径不同版本提示移除旧文件，失败可重试。关闭时当前文件完成后暂停剩余任务。
- 附件弹窗以局部副本编辑，确认时复核状态/权限，取消不变更原关联。
- SourcePreview 保留 `file / step / evidence` 接口，新增可选 `dual` 显示模式：资料管理宽屏同时展示原文件和解析文本，窄屏保留页签切换；工具准备页继续使用紧凑的原文件/解析文本页签。PDF 使用浏览器原件预览，DOCX 使用 docx-preview，XLS/XLSX/CSV 使用 SheetJS 多工作表和分页，图片显示真实原件。Excel 保留第一行数据，以列字母作表头，不将第一行误作业务字段。
- 不制造 PDF 总页数；未知总页数仅允许输入页码。页码证据仅驱动 PDF 导航。旧 DOC 等不支持格式明确提示下载或查看解析文本，加载/转换失败明确展示错误。
- 原文件地址只接受 HTTP/HTTPS/blob，拒绝账户密码和脚本/HTML URL；canDownload=false 阻止源文件请求；跨域 Office 请求不携带本站凭据。来源 URL 只在当前预览中使用，不写入长期文件选择。DOCX 禁用 altChunk，清除危险链接。

## 边界

浏览器使用演示数据及本地接口响应夹具，不代表真实后端权限验收。服务必须最终执行空间/文件/目录权限检查、上传重名策略、事务一致性和下载鉴权。拖入文件支持 FileList；浏览器拖拽文件夹不保证展开，请使用“选择文件夹”。上传没有分片续传和服务端进度，仅以完成文件数量表示进度。预览需服务端提供可访问原件或转换 PDF，跨域 Office 原件需 CORS。PDF 自动化只检查 URL 和页码绑定，不验收原生 PDF 内容渲染；未知页数不表示输入的页面确实存在。大 Excel 在前端读取全工作簿，50 MB 上限检查发生在下载之后，超大文档应由服务端转换。Office 转换失败可切换文本，不对 DOC 提供假预览。不持久保存浏览器关闭前的上传队列。中文测试模拟组合输入事件，仍建议使用实际部署电脑的输入法验收。
