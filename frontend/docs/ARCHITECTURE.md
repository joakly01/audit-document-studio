# 前端工程设计

本工程是 Vue 3 + TypeScript 业务前端，独立于 `优化方案/交互原型`。不加载旧原型的全局覆盖脚本，不通过 iframe 嵌入旧页面。正式运行默认访问原系统接口；演示数据必须通过 `VITE_DATA_MODE=demo` 显式启用。

## 目录与职责

- `src/domain`：业务类型、工具登记、提交校验、选择集合、请求/响应转换。服务端字段集中映射，不散落在模板。
- `src/services`：HTTP、API 服务、独立演示服务、原代码兼容算法。API 错误不能自动切到演示数据。
- `src/stores`：Pinia 工作区草稿。预览文件、查找集合、本次分析集合分开。
- `src/components`：资料选择、文件预览、附件、提示词编辑和字段编辑。
- `src/components/config`：招投标项目角色、台账映射、词频和提取配置。
- `src/components/results`：各工具专用成果、证据与导出。
- `src/views`：资料管理、准备工作区、结果、任务中心、提取模板、提示词库。
- `tests`：业务与接口契约测试；浏览器测试独立验证操作路径。

## 业务约束

1. 选择本页与全部页为不同动作；选择器操作暂存，确认才修改工具范围。搜索和翻页不能改变已选全集。
2. 解析状态与分析任务状态分开。只允许有权限且解析完成的资料参与分析。
3. 信息提取无默认模板、无默认字段；其他工具按对应功能类型加载默认系统提示词。个人提示词可选择、编辑并另存。
4. 附件是本次输入；再次分析修改附件不回写原任务，也不自动改资料级关系。
5. 提交配置要冻结。再次分析创建可编辑草稿，确认后生成新任务；不可覆盖历史。
6. 原文按需加载。来源无页码时不补第一页，无证据时不关联第一份文件。
7. 工具提交后在当前结果页显示真实阶段与进度。任务中心是统一记录入口，不是必经中转。
8. 三栏保留信息提取、词云、主题、时间轴、会议、风险、费用；复杂规则和角色工具使用两栏。
9. 任务中心操作固定为文字“查看结果 / 任务信息 / 导出数据”。准备页无设置导入导出；词库、提取模板及成果导出仍保留。
10. 未确认的接口和单位必须显式报错或禁用，不得造出成功状态或下载假报告。

## 宿主集成

Hash 路由支持独立静态部署，也支持 `?embed=1#/tool/extract` 隐藏导航，嵌入宿主框架。身份沿用同源 HttpOnly Cookie；如宿主使用 Bearer Token，可从内存提供 `setTokenProvider`。不在 URL、localStorage 或源代码写入登录凭据。

API 基础地址、开发代理和专用接口扩展通过环境变量配置。详见 API-CONTRACT.md。服务端仍需验证创建、查看、附件、原文与导出权限，前端禁用不构成授权边界。

## 原源码复用

原 `前端代码/` 保留为依据；涉及算法兼容的纯配置工具放在 `services/legacy`，注明来源与迁移边界。不重写后端计费、AI 分析、项目匹配和调度算法。缺失的 API 包装与真实返回样例在对接文档列出。

## 数据与生命周期

草稿由 Pinia 保存，切换面板不销毁草稿。历史再次分析的 sessionStorage 传递只存当前标签页并在消费后移除。轮询采用完成后再安排下一次请求，终态和卸载清理；网络失败不改变业务状态。文件预览有取消/失效序号，避免慢响应覆盖新文件。

## 验证边界

单元/契约测试证明载荷与前端状态逻辑；演示浏览器回归证明界面流程。真实后端、权限、队列、模型质量及大规模运行需要在业务环境联调。不得将演示通过写成生产联调完成。
