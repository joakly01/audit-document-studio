## 交付状态

`frontend/src` 是新开发的 Vue 3 + TypeScript 业务前端，资料、配置、模板、提示词、任务与结果分别由组件和服务层实现。已完成本地可运行实现和前端验证，尚未接真实业务后端验收。

前端开发阶段没有发布到 Sites、远程服务器或生成部署包。Git 提交以仓库历史为准。原 `前端代码`、方案和交互原型保留作为对照依据。

## 本轮重要修正

- 合同自动识别按原源码仅提交必要开关，指定类别才提交规则与双阶段提示词。
- 工程字段支持任意 F 键和逐文件配置，移除字段只裁剪受影响规则。
- 两表优先判断支持组合规则；删除被引用的字段需确认。
- 词库与任务词表分离，选用词库不抹掉手工输入，冲突需明确处理。
- 修复 DOCX 容器挂载前渲染，以及两表配置被原生 template 元素隐藏的问题。
- 兼容原任务明细、大写字段、多层 JSON 和各工具已知结果结构；未知内容原样保留。
- 词云接原专用结果接口；合同报告状态独立轮询；演示 Excel 为有效工作簿，演示报告明确为 TXT。
- 原删除/终止共用接口存在任务完成瞬间误删历史的竞态。真实模式改为配置独立取消接口后启用停止，不再调用旧删除接口。
