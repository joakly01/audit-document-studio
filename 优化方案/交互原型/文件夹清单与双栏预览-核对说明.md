# 文件夹清单、双栏预览与嵌入布局

2026-10-18。本说明覆盖本轮增量，以此修正历史页面示意。

## 原前端核对

原 `前端代码/views/file-manager-code/Index.vue` 的文件夹筛选表保留文件类型、数量、总大小及文件名称；预览弹窗采用原件与解析内容两栏，并提供 Excel、Word、Markdown 导出。原预览调用 `previewFileAPI(file_id)`，解析内容调用 `getFileContentAPI(file_id)`；DOC/WPS、XLS 分别沿用原转换接口。原 `components/FilePreview.vue` 承担格式展示。上述原代码未修改。

## 本轮交互

- 上传文件夹：在类型筛选表中增加“文件名称 / 相对路径”，直接展示前三个文件，多于三个时进入完整清单。清单支持路径/名称搜索和50条分页，同名不同目录可区分。返回后保留类型勾选，继续上传仍按原类型筛选结果和目录层级执行。
- 文件预览：左“原始文件”、右“解析内容”，同时展示，各自滚动。PDF支持翻页和缩放；Word直接展示DOCX原件；表格展示真实工作表及单元格，支持切换工作表和200行分页；文本、图片、音视频分别读取原始字节。解析未完成时仍可查看可用原件；原件缺失时已有正文独立保留。
- 导出：下载原文件保留原始字节；解析内容单独导出 Excel、Word、Markdown。Excel长正文按30000字符分段，避免单元格截断。操作前复核查看和下载权限。
- 任务中心：按最新要求，移除资料管理操作栏及更多里的入口，统一从左侧导航进入；当前位置旁不再显示锁图标。目录权限和只读操作约束保留。上传记录继续描述文件上传/全文识别，任务中心负责分析任务，二者不混淆。
- 嵌入布局：移除所有页面最上方全局面包屑/账户/帮助栏，直接呈现业务内容。资料区的“当前位置”与工具页面自身名称保留。手机保留紧凑导航入口；桌面左侧导航和帮助入口保留。

## 数据与正式接入边界

本地预览从浏览器保存的 File 或内置验证资料的实际格式文件读取，不拿解析文本冒充用户上传的原件。127份内置资料补充了可打开的 PDF/DOCX/XLSX 等文件；没有导入工作区真实业务资料、截图或会议纪要。状态验证资料及故意缺失原件的分支不自动补造原件。

正式接入仍调用现有预览、正文和格式转换接口。DOC/WPS及特殊格式依赖原后台转换能力；当前前端无法保证复杂Office版式与原应用逐像素一致，表格预览优先核对单元格，完整原件可下载。没有新增后台分析逻辑，没有接通内网、OCR或OSS服务。

Word组件和依赖同源托管，沙箱隔离原件渲染，禁用外部资源和altChunk；解析正文转义后展示。切换文件/关闭窗口会取消渲染并回收临时地址。组件版本及许可随 `dist/vendor` 交付；源文件映射记录SHA256，生成工具在 `tools/build_source_fixtures.py`。

## 验证

`tests/browser_folder_preview.py` 覆盖文件路径、完整清单搜索分页、筛选保留、三类原件展示、原件与解析正文独立、缺失/失败状态、三格式导出、快速关闭、左侧任务入口及四种预览尺寸。上传、状态清单、上传记录、文本检索和低矮布局使用已有回归脚本核对。

## 本页与全部页选择

表头明确标注“本页”，只处理当前页文件，不勾选文件夹。选中后，在表格底部显示当前结果选择范围，并可显式“选择全部页（N份）”；此N仅包含当前空间、目录、子目录范围、搜索、状态及类型筛选下具有查看权限的文件。

“仅保留本页”和“取消本范围选择”仅调整当前结果，保留其他目录、其他空间及筛选之外的已选文件；“清空已选”仍处理全局选择。选择保存为明确文件ID清单，新增文件或改变筛选不会暗中自动选入。正式对接若列表由后台分页，需沿用现有查询条件逐页获取有权文件ID，不能把当前页条数冒充全部数量；批量执行前继续复核权限。前端明确选择范围，无需改变后台核心处理逻辑。

`tests/browser_selection_range.py` 核对当前页、半选、全部页、跨页保留、筛选范围、取消范围、跨范围已选保留及低矮布局。
