# 资料选择范围与中文输入修复

2026-10-19。沿用共用资料选择器及资料管理数据/权限模型，不修改原始前端或后端接口。

## 本页与全部页

- 资料选择表头明确“本页”，仅选择/取消当前页可选文件；文件夹占用原有分页行，但不计入已选文件，也不隐式展开子目录。
- “选择全部页（N份）”采用当前空间、目录、名称查询及“仅本级/含子文件夹”条件，汇总全部页可选文件。权限、附件排除主文件、检索资料资格等仍来自共用 `pickerItems`，不另建宽泛选集。
- 半选、已选本页、当前范围全部和其他范围已选分开提示。保留“仅保留本页”“取消本范围选择”，均保留其他范围的既有选择。
- 翻页保留勾选，勾选保持滚动位置，翻页或改变搜索后文件列表回到顶部。低矮窗口固定可达分页和确认区；手机外层滚动保留位置。确认前暂存，取消不改工具原资料；选表仍单选。
- 正式服务分页接入仍需用既有后端的筛选选集及排除项表达“全部页”，不能把当前已加载页当全量；本地交互沿用完整资料集。

## 中文输入

根因是目录过滤在每次 `input` 时重建输入节点，打断输入法组合。`input-composition.js` 在业务监听器之前注册，组合期间不触发业务刷新，选词结束后只提交最终输入；兼容浏览器最后一次 input 在 compositionend 前/后或缺省的不同顺序。选词过程的 Enter 不冒泡到查询/提交动作，不取消输入法默认行为。

覆盖资料管理目录/文件名、资料选择目录/文件名、工具资料目录、模板分类及共用表单。直接输入、粘贴和原查询交互保留；中文选词期间不改变执行或选择范围。
