# 资料管理：操作层级与紧凑布局

## 设计判断

这是资料密集的审计工作台，优先级为阅读资料、选定范围、检索正文、使用分析工具。低频管理应保持可发现，但不长期占用主工作区。清晰可辨的图标与大按钮是两个不同问题：目录管理使用标准省略号，修正圆点尺寸和对比度，保留悬停、焦点与目录名称提示，不用大面积文字按钮。

参考 [Ant Design Dropdown](https://ant.design/components/dropdown/) 对多项操作的下拉组织方式，以及 [IBM Carbon Data table guidelines](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines) 对表格工具栏、批量操作和行内操作的区分。本项目在这些成熟模式基础上，进一步按审计工作台的资料密度处理空间不足，不通过缩小字体或增加按钮行数容纳次要操作。

## 页面职责

| 区域 | 保留内容 | 收纳与克制 |
| --- | --- | --- |
| 独立页头 | 取消 | 不重复展示资料管理标题与总数，释放核心高度 |
| 位置与主工具栏 | 当前路径、文件名搜索、上传资料下拉、更多；宽度允许时显示范围与筛选 | 原列表位置行合并进操作栏，不保留独立资料列表标题 |
| 文本检索 | 更多中的第一项 | 单一入口，保留独立资料范围与全部检索能力 |
| 选择信息 | 已选数量和取消选择并入已有分页栏，列表排序进入更多 | 不新增状态行；跨目录勾选仍可核对 |
| 更多菜单 | 所选资料操作：移动、重新解析、删除；目录与视图：列表排序、权限说明、分析工具显示、上传记录 | 分组、对象明确；文本检索只在更多中保留一个入口；没有可操作对象时说明并禁用 |
| 文件夹行 | 打开、轻量省略号 | 省略号进入目录管理，含原新建下级、重命名、权限、引用和管理员操作；低频功能不突出 |
| 文件行 | 文件名查看原文；下载、附件、轻量省略号 | 省略号打开完整详情与管理，重命名、移动、删除等不丢失 |
| 目录树 | 名称、展开箭头、省略号；管理员拖动手柄 | 省略号常驻但无大边框与底色，悬停和焦点时增强；不增加文字按钮 |

只读、引用或归档等真正影响操作的状态使用小锁图标及可读提示，不把项目根节点“不能直接上传”误标成整个目录只读。权限页解释完整能力，上传和删除等入口继续校验实际授权。

## 空间适配

依据中间资料区的实际可用宽度适配，而不是仅依据浏览器宽度；因此左侧菜单折叠、目录拉宽、右侧工具区显隐都能触发收纳。

- 中间资料区宽度不低于900px：范围、筛选、上传和更多在同一行，文本检索在更多。
- 中间资料区720–899px：范围进入筛选，筛选、上传和更多保留。
- 中间资料区低于720px：范围和筛选进入更多，名称搜索、上传和更多保留。
- 移动已有表单节点，保留筛选值，避免同一个筛选项出现两个副本。
- 主操作字号仍为 16px，辅助文字不低于 14px；工具栏约 58px；不保留独立选择/排序行，勾选前后不增加独立位置或选择行。
- 下拉菜单按屏幕高度限高并内部滚动，点击外部或 Esc 关闭，方向键可进入，Esc 返回触发按钮。

更多只是展示收纳，不重新定义后台逻辑。文件夹拖动排序、跨空间选择、解析、删除确认、权限与历史引用规则沿用原实现；原始 Vue 代码及后端接口未修改。

## 验证

`tests/browser_compact_actions.py` 覆盖 1440 / 1366 / 1280 / 1024 / 390 五种窗口宽度、选中与未选中共十组布局，以及实时缩放后保留范围和筛选、菜单浮层边界、键盘与焦点、只读提示、批量确认和工具区恢复。截图和布局数据在 review/compact-actions-*。

继续执行资料管理、文本检索权限和拖动排序回归。该说明替代上一轮“移除更多”“管理使用文字按钮”的设计，最终原则是让高频任务突出、低频功能按需展开，不以展示按钮数量判断功能完整度。

## v1.1 补充

空间显示顺序统一为公共空间、项目空间、个人空间，不重置当前空间。省略号为三个实心圆点，拖动手柄为六个实心圆点。图标语义、图形和 SVG 资产见 [图标规范](../UI界面规范/05-图标规范与图标表.md)。目录拖动继续沿用原超级文件管理员与同级排序约束。
