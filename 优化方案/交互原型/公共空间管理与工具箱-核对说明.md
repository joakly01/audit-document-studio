# 公共空间、工具箱与上传入口：核对说明

2026-10-18。依据原 `前端代码/views/file-manager-code/Index.vue`、`api/fileManager.js` 及用户提供的截图逐项核对。原前端源码保持原样；本目录维护优化后的界面和交互。

## 公共空间管理

| 原能力 | 界面和权限处理 |
| --- | --- |
| 新建文件夹 | 在目录区入口或目录省略号中操作；公共根目录仅超级文件管理员可新建。机构绑定根目录不直接新建子目录；已有深层目录按原权限管理。 |
| 重命名 | 按创建者、项目角色和系统内置目录规则显示；管理员身份不直接替代原创建者条件。 |
| 权限管理 | 公共目录独立入口；管理权限、可分权标记、系统内置及未授权目录限制分别检查。个人/项目空间不另建一套用户授权。 |
| 绑定项目 | 独立窗口，支持搜索和分页，保留已有未知项目；只修改项目关联，不覆盖机构字段和文件路径。 |
| 绑定机构 | 独立窗口，仅超级文件管理员；默认勾选为机构授予查看权限，可包含下级机构；不覆盖项目关联，不降级现有管理授权。解除绑定不隐式撤销其他授权。 |
| 删除 | 按原管理、创建者、内置目录及引用规则显示；提交前再次校验并保留确认。 |
| 系统内置目录 | 管理员在公共/个人空间创建时可标记，普通用户不显示选项。 |
| 目录聚焦 | 公共空间显示已绑定机构目录及其祖先路径；祖先只作导航结构。个人空间保留完整目录。 |
| 拖动排序 | 原超级文件管理员、同级排序限制继续保留，支持拖动、键盘和上下移；与被移除的文件列表排序是两项不同能力。 |

只读、OSS或引用目录不借由新增菜单获得修改权限。授予普通管理权限不等于授予分权，也不自动授予绑定机构权限。授权表展示对象类型、权限、分权/下级机构范围、授权人及时间；搜索和调整级别保持表单草稿，撤销可取消。

正式接入继续复用原接口：

- 目录创建、重命名、删除及同级顺序继续使用原 `createFolderAPI`、`renameFolderAPI`、`deleteFolderAPI`、`updateFolderOrderAPI`。
- 项目关联：PUT `/api/v1/file-manager/folders/{id}/bind-project`，`project_uuid`；项目列表沿用原搜索分页接口。
- 机构关联：PUT `/api/v1/file-manager/folders/{id}/bind-org`，`bound_org_uuid/grant_read_to_org/grant_read_include_descendants`。
- 授权列表/新增：GET/POST `/api/v1/file-manager/folders/{id}/permissions`；撤销：DELETE 同路径下的 `/{permissionId}`。
- 正式授权用户查找继续沿用原远程用户搜索与机构树，不将当前浏览器交互用的对象列表当成真实组织目录。权限及403等结果以服务端为准。

## 工具箱、更多与状态

工具箱常态宽260px，中等窗口240px、小屏桌面210px，移动端按需展开。选中提示移至表格底栏，显示“已选文件、解析完成、解析未完成”，数字分别强调；详细解析中、失败/积压等状态在提示和清单中核对。权限变化单列。进入工具继续按格式、解析和权限核验，不把“完成”误认为适合全部工具。跨目录选择保留。

按用户最新要求，取消“未关联原文”独立状态，未完成资料按未解析处理；尝试识别且实际缺少文件时，仍在操作反馈中说明补充要求，不伪报解析完成。

“更多”按检索与记录、窄屏筛选、所选资料、目录与界面分组；文本检索第一项，上传记录仅一个菜单项，移动/重新解析/删除只处理勾选范围，目录权限和工具箱显隐放底部。移除文件列表排序入口，保持默认上传时间顺序，左侧目录拖动不受影响。操作栏继续保持单行。

## 上传入口重新设计

上传位置在窗口标题下明确显示。一个完整的拖放区内，并列提供“选择文件”和“选择文件夹”；文件夹保留层级与文件类型筛选。选择前不出现空进度区；选择后新增本次上传清单，显示文件名、实际目标、进度、完成/失败数量与错误重试。按钮写清选择后自动上传，避免误以为还需要提交一次。

原100MB限制、多文件、目录API及兼容选择器、空目录、同名目录合并、同名文件覆盖/跳过、子目录权限复核、类型筛选、真实解析和工具内添加资料继续保留。失败不伪装成成功，关闭窗口不删除已提交记录；关闭浏览器不代表后台已接续任务。

## 验证与接入边界

浏览器验证涵盖公共目录管理与上传界面6组、原资料管理14组、文本检索及权限10组、文件夹上传13组、目录拖动9组、上传记录12组；另验证13种资料区布局与紧凑菜单。证据在 `review/*results.json`、`review/upload-refined-*.png` 与 `review/toolbox-selection-refined.png`。

本轮为前端高保真交互，并执行浏览器本地原文件保存和可支持格式的实际解析。未连接内网业务后台、真实组织目录、OSS/OCR服务；这里的角色与权限验证不替代服务端鉴权。正式接入沿用原接口和大逻辑，布局调整不要求重写后端。
