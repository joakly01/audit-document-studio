# 提取模板：原功能核对与接入说明

2026-10-18。导航及页面改名“提取模板”，聚焦信息提取的字段定义，不将全部分析工具的方案混为一类。

## 核对依据与边界

已核对用户提供的三张截图，以及原 `前端代码/api/template.js`。当前交付源码中未找到完整模板管理视图组件，因此目录和编辑交互参照截图，接口和字段契约以该API文件为准；权限枚举、删除目录的后端行为仍需正式服务联调确认，不把截图当前账号的可见按钮当成所有人的默认权限。

原截图的重要信息：系统/个人多级目录；目录新建子目录、重命名、删除；名称查询和15条分页；模板名称、描述、字段数及操作；模板基本信息、所属目录、字段名称和字段描述；字段新增/删除；独立字段列表。以上在当前前端均有入口。

| 原能力 | 当前界面与行为 | 原接口 |
|---|---|---|
| 目录树 | 左侧分类树，保留系统与个人根分类及多级子分类 | `getDirectoryTree` |
| 目录管理 | 实心省略号菜单；新建子分类、重命名、删除空分类。根分类不可重命名/删除；非空分类提示先清空 | `createDirectory` / `updateDirectory` / `deleteDirectory/{directory_uuid}` |
| 查询列表 | 名称查询、Enter查询、空结果、页容量、上一/下一页、页码跳转 | `getTemplatesByDirectory` |
| 查看详情 | 独立字段表：序号、名称、提取说明；说明为空时显示按字段名称提取，可搜索字段 | `getTable/{prompt_uuid}` |
| 新建/编辑 | 名称、描述、所属分类、字段名及提取说明；编辑保持所属分类，新增/复制可选有权个人分类 | `createTable` / `updateTable` |
| 字段配置 | 支持增删与上/下移；至少一字段、名称必填且不重复；字段描述选填，保持原截图允许空描述的行为 | `prompt` 中的字段数组JSON |
| 删除模板 | 独立确认，并在提交前复核权限；既有任务与当前工作区副本保留 | `deleteTable/{prompt_uuid}` |
| 导出配置 | 列表操作列直接导出，字段列表也可导出，保留名称、描述及完整字段JSON | `exportConfig/{prompt_uuid}` |
| 用于信息提取 | 系统/个人模板统一可选；确认后同步名称、字段与说明，保留已选资料和切片参数 | `getPublicAndPrivateTemplates`，提取任务沿用既有字段负载 |

原列表接口按单一目录分页；当前前端上级分类展示下级分类的模板并明确“含下级分类”。正式接入可用目录树枚举已有子目录并沿用原查询接口聚合，再统一名称筛选和分页；不把单页结果当作全部数据。若服务原本支持递归范围，应优先使用已具备的能力；这不要求修改后端核心提取逻辑。

## 页面与编辑设计

- 与资料管理统一为连体左右工作区。单行工具栏显示“当前位置”、可返回上级的分类路径、名称搜索、新建和更多，不重复增加页面标题栏。左侧补充分类搜索和刷新，列表与目录分别滚动，底部分页固定。
- 模板名称与字段数量突出，列表直接显示“使用模板、复制模板、导出配置”，使用资料管理同样的文字操作；有权编辑、删除时显示行内实心省略号，否则不留空菜单。名称和字段数均可进入字段详情，不再重复放置“查看字段”按钮。行高与资料列表一致，长描述最多两行，完整描述可在详情中查看。
- 字段编辑使用紧凑表格，避免每字段占一个大卡片。模板基础信息在上，字段为核心区域，取消/保存固定在底部。短窗口中基本信息压缩为同行标签，不缩小正文。
- 字段顺序决定输出列顺序。模板修改暂存，关闭时可继续编辑或放弃；编辑保存保留当前分类、查询、页码与列表滚动位置，调整较后字段保留编辑表格视野。保存后不偷偷替换工具当前配置。使用模板是独立确认动作，既有任务快照保持原状。
- 系统模板普通用户可查看、使用、复制与导出；系统维护依赖独立模板管理授权。个人模板可修改属于本人的内容，提交时再次复核。模板管理授权不借用文件管理员权限，也不提供界面角色提升开关。
- 所属目录、字段和提取说明由数据驱动。其他工具原有的提示词、方案另存及下拉选择保留在各工具；不会因为缩小本页范围而删除浏览器已有的其他工具模板。

## 与原服务的适配

字段规则继续使用 `{name, description}`，原API将规则数组序列化到 `prompt`。不新增一个与此冲突的顶层提示词字段。空字段说明仅在应用到工具时补成按字段名提取的默认要求，以兼容现有工具对非空运行说明的校验；不改写模板保存值。

当前前端导出包含 `template_name`、`template_desc`、规则JSON `prompt`、分类信息及可读目录路径。导入支持该结构，以及先前信息提取工具导出的版本2配置；导入后先核对，再保存为新模板。其他工具配置不作为提取模板导入。JSON文件上限2MB，拒绝危险属性与不合法规则，字段新增上限200为当前前端交互保护，正式接入需与服务允许范围对齐。

真实服务中的 `prompt_uuid`、`directory_uuid`、`pid`、`path_uuid`、`path_name` 应沿用返回值映射，不发送本地目录标识。`template_type` 的0/1与系统/个人的具体对应关系，在现有API注释中没有完整枚举说明；当前不凭UI推断赋值，导出仅在已有类型值时保留。创建和更新应由正式适配层明确沿用业务枚举，避免原兼容API默认值影响模板归属。

系统管理权限在本地交互中使用独立的 `state.templateAdmin` 能力标记核对分支，默认关闭；正式服务必须由登录账号权限与后端鉴权决定，不应信任前端标记。浏览器存储不等于服务端用户隔离。

## 当前可验证范围

本轮没有修改原Vue源码和后端接口。模板在本浏览器保存，初始模板及字段用于完整操作验证，没有同步工作区真实模板或连接正式模板库。系统内置覆盖4/36/12/16/1/24字段模板及个人模板，实际业务模板应从原服务读取后再逐项核对。

- `tests/browser_extraction_templates.py`：11组功能检查，覆盖分类/查询/详情/复制/字段校验/暂存取消/目录管理/刷新持久化/导出导入/工具应用与执行/权限重查/其他工具方案/分页；四种尺寸1440×900、1366×768、1024×480、390×600。
- `tests/browser_config_regression.py`：保留版本2配置导入和切换的回归，核对词表、会议筛选、两表硬规则未受影响。
- `review/extraction-templates-results.json` 与 `review/config-regression-results.json` 记录结果，界面证据在同目录。

现有提取执行仍为本地操作验证逻辑，不因本轮模板页面调整而成为真实模型提取服务；字段映射和任务快照联动可验证，实际提取准确性仍需正式服务验收。

## 资料管理风格复核

本轮以资料管理实际样式为基准核对：统一连体面板、240/220px左栏、58px单行工具栏、灰色表头、表头14px/正文16px/辅助14px、约75px列表行高、底部分页、文字操作、实心省略号、下拉菜单、输入框与弹窗的圆角/分隔线。保留提取模板业务所需的名称、描述、字段数和分类，不机械复制文件状态等无关列。

新增 `tests/browser_template_consistency.py`，检查资料/模板表头与边框的实际样式一致，分类查找和当前位置导航可用，编辑保存保留上下文，36字段操作不跳回开头，超长描述不撑坏列表及详情；四种窗口尺寸保持单行工具栏和可见分页。原11组模板检查和5组工具配置回归继续通过。原Vue和后台接口未修改。
