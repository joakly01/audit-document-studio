## 打开与体验

在本目录运行：

    python3 -m http.server 8765 --directory dist

打开 http://localhost:8765。无需安装前端依赖或构建。

从资料管理勾选资料后进入工具，或进入工具后添加资料。确认配置后执行，结果可核验来源并导出；历史任务和个人模板在当前浏览器保存。上传原文件在本浏览器保存，支持刷新后下载与继续解析。需要通过本地服务器或已发布站点运行，不能用双击文件的方式验证 PDF 解析等模块功能。

## 原型边界

**这是可操作的前端原型，不是真实审计分析系统。**

1. 内置文件与结果均为虚构示例。引用来自同一组示例资料，不上传工作区原始截图、会议纪要或业务源文件。
2. makeResult()、run()、sendChat() 等采用本地演示逻辑。配置保存与交互有效；提示词、切片、评分、锁定等并未调用正式模型算法，相关参数仅进入快照。二次筛选为固定规则演示。
3. 词频使用示例词表及自定义词的文本计数，不是正式中文分词服务。
4. 六类费用各有构造合同约定（百分比或固定价），用于操作评审，不能视为通用收费标准。
