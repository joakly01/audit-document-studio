## 二、共同流程

1. 左侧固定“添加资料”，从资料库选择文件或多级目录，也可沿用上传文件/文件夹；目录、文件混合显示，分空间组织。
2. 中间显示本次范围、位置与解析状态；点击目录仅过滤视野。文件打开原件和解析内容双栏。管理模式多选移出并可撤销，源资料不删除。
3. 右侧按实际分析阶段选择提示词。编辑暂存，应用后才改变本次配置；系统原件与历史任务保留。另存只保存当前阶段提示词及其原有配套规则；完整配置导入、导出为独立低频操作，不与普通选词混用。
4. 顶部唯一主操作“开始分析”，提交前集中填写任务名称、备注及提交后去向。执行显示逐文件状态，保留任务中心、停止、部分失败与重试。
5. 完成后默认收起配置，聚焦结果。切换结果视图、搜索、选文件和筛选均不重新执行；“本次配置”查看只读快照，“复制新建”复用配置并保留旧任务。
6. 分析结果以原文来源为核验入口。文件解析完成、任务执行完成、发现待核验线索分别表达，不能互相替代。

## 三、逐项功能核对

### 词云分析

- 保留停用词/用户新词两类词库、按类型及关键词查询、分页、增改删、TXT 导入。增加可回读的 JSON 导入/导出。
- 导入先预检，显示另一类型冲突、同类已有、文件内重复；可逐行忽略/覆盖，也可批量处理。加入清单后再保存词库，取消不影响正式清单。
- 执行前选择本次用词，两类均支持全选/清空；词条不超过64字，两类不允许重复。
- 展示词数保留10–500范围，属于展示参数；词云、词频表与组合视图可切换。按文件查看时重算当前文件频次，避免仍显示全任务总次数。
- 点击词语查看各文件出现次数、原文片段，进一步打开原件与解析内容并定位词语。加入停用词明确“下次生效”，不改写本次结果；复制新建时带入该选择。
- 保留词云图片与明细下载，历史任务的用词快照随导出保留，不能被新词库覆盖。词频只反映出现次数，不解释为风险程度。

### 会议纪要分析

- 常规分析保留“按议题归类”“按会议查看”“议题清单”；可查看会议名称/日期、议题名称/内容、金额（万元）、参会/列席人员、自定义扩展字段及来源。
- 议题相似度0–100%、最小聚类数1–20保留；常规提取和风险分析提示词独立配置，不能混用。
- 保留人员、起止日期、金额上下限、关键词/正则筛选；无金额与金额为0应区别。全部议题独立清单支持会议/主题/关键词筛选、重置与Excel导出。
- 保留导入已有 Excel/JSON 结果入口；沿用原导入校验，不要求为已整理的数据重复执行。
- 风险分析继续基于本次会议和议题生成报告，明确为独立阶段。保留七部分：基本情况、会议时间线、经济议题总清单、风险分析、跨会议追踪、风险事项总表、审计结论与建议。
- 报告保留章节导航、证据来源、调整下一次报告要求、重新生成、失败重试与Word/Excel/Markdown/JSON下载；更改报告要求不改写已完成的常规分析配置。
- 深度问答保留建议问题、输入/发送、等待状态、回答来源、保存与清空。Enter发送，Shift+Enter换行，中文输入法组词时不误发；问题长度校验失败保留草稿。

### 风险点分析

- 风险点名称、层级路径、检查说明、选用状态均可配置，支持增删、全选、清空、必填及同名校验。
- 原有 `byRisk` / `byFile` 两种遍历方式保留，默认逐关注点检查各文件，两种均覆盖全部所选资料及关注点。
- 结果可按风险点或文件归组，搜索风险点/内容/证据，按匹配线索、未匹配线索、资料不足或全部查看，支持整体及分组展开/收起。
- 原返回的风险等级 `level` 如有值则显示并导出；未提供不生成等级。结果状态“需核验”与等级分开，不把关键词匹配认定为已确认风险。
- 每条保留原文摘录、检查说明、来源文件和双栏核验入口；未匹配不能解释为不存在风险。Excel等明细导出保留风险路径、等级和证据。

### 时间轴分析

- 保留系统/个人提示词和本次编辑；任务运行后按快照查看。
- 日期从文档事项内容取得，不用上传时间补填。未知日期单独成组；日期合法性校验避免2月30日等无效日期进入结果。
- 默认从晚到早，保留切换从早到晚、日期范围、结果/文件搜索、按日期分组、文档章节/事项详情、整体展开/收起及逐项展开。
- 时间轴与事项列表两种视图均保留原文来源；导出逐章节保留日期、文档、摘要和来源。

### 主题归纳

- 基础信息提取和主题归纳为两个独立提示词阶段。各自从提示词库选择、编辑和另存；选词仅替换对应阶段的ID和正文，不覆盖另一阶段或其他分析参数。
- 结果分为主题阅读和基础信息表，均可回到来源核验；保留全宽结果区域与导出。
- 归纳阶段失败时保留已取得的基础信息，可先查看信息表，再仅重试归纳阶段，不重复读取源文件。

## 五、边界与验收

当前站点是独立前端交互实现，尚未连接内部分析、调度、词库和权限服务。资料上传/预览/导出可实际操作；本地词频使用浏览器分词候选和正文计数，会议/风险/主题结果为有限规则驱动，只用于验证交互，不代替正式模型、语义聚类和审计判断。相似度、提示词及遍历顺序进入配置快照，正式算法由原后端执行。

资料权限沿用共用前端判断，提交、结果来源与导出时再次检查；这不能替代服务端鉴权。页面刷新会中断本地计时任务，不具备真实后台持续执行能力。正式接入时应替换执行/轮询/重试/问答驱动，保留本轮的工作区布局、配置编辑、报告与证据呈现。

验证脚本和证据：`tests/browser_analysis_workflow.py`、`tests/browser_analysis_edges.py`、`review/analysis-*.png`、对应 checks JSON；并回归提取模板、信息提取及共用配置编辑。界面规格见配套 UI 规范第15号补充。

会议议题以“会议时间轴”为默认阅读视图，与“同类议题”联动，并保留“议题清单”；不以普通“会议顺序”列表替代时间轴。分组与明细独立分页，同类议题导航每页15组、议题明细每页20项。完整当前筛选范围决定动态扩展字段列，分页只替换行，不能导致自定义字段忽隐忽现。统一保留参会及列席人员、日期、金额、关键词及有限表达式筛选，全部议题弹窗的独立搜索、筛选、重置和Excel导出，以及原JSON/Excel结果导入。筛选改变后返回首页，导出覆盖完整匹配范围而非当前页。

风险准备页使用“添加核查资料 / 设置检查内容”，主按钮为“开始核查”。风险点名称、层级路径、检查说明和选用状态保留，支持检索、增删、全选、清空和编辑校验；草稿取消不修改当前配置。检查方式的界面名称为“按风险点逐项检查 / 按文件集中检查”，仍映射原 `byRisk/byFile`：前者以单个风险点×单份文件或片段为调用粒度，后者以单份文件×全部已选风险点为调用粒度，两种都覆盖所选范围，不能解释为仅改变显示顺序。

风险结果按“待核验线索 / 未见线索 / 资料不足”表达，支持全部入口、按风险点或资料归组、搜索与资料范围筛选。原风险等级有值则保留，无值不推算；原文证据、检查说明和来源核对保持。每页8组，每组先展示5条再逐步展开，当前筛选导出与状态、搜索和资料范围一致，分页和展开条数不限制导出。页面、计数和导出沿用共用的历史读取与下载权限口径。

数值连续编辑不重建输入框，相似度空值不应被转换为0而通过提交；保留0–100%及1–20整数的原参数限制和百分数到0–1的请求映射。低高度、小屏使用内容区和弹窗内部滚动，表格保留横向滚动，主要操作和分页可达，不通过缩小文字适配。

对应交互验证位于 `tests/browser_audit_analysis.py`，证据记录于 `review/audit-analysis-checks.json` 及 `review/audit-*.png`；通用分析工具与任务结果入口继续由既有回归验证。具体通过结果以检查记录为准，本说明不作为正式服务验收结论。模型分析、语义聚类、队列调度、后台持续执行、真实SSE问答、权限服务与服务端鉴权仍需原后端联调；当前仍为独立前端演示。

### 会议时间轴恢复与独立演示

再次对照原 `MeetingTimeline.vue`、`TimelineClusterSwitch.vue`、`ClusterResultPanel.vue` 和会议页 `applyLocalFilters`，将按时间对照决策的能力明确为默认视图。日期下归入各次会议，会议下展示议题，日期、会议与议题内容独立展开；同日多会议和未提取日期分别处理，不用上传时间补会议日期。

选中同类议题时，跨会议高亮命中内容，展开所在日期和会议并定位首项；重复选择仍能重新定位。点击时间轴议题反向选中类别及其明细。该联动是阅读状态，不能隐式缩小本次分析或筛选导出范围；跨日期页的目标应先到目标页再定位。大量资料保留分批展示与分页，原文核对返回保留阅读上下文。

人员条件同时匹配参会与列席人员。日期、金额、关键词与有限表达式统一驱动时间轴、同类议题、清单和当前筛选导出；关键词同时覆盖类别、独立议题名称和内容。沿用当前未知金额与0分开的口径，不复刻原本地筛选将未知金额转0的缺陷。筛选后同步更新统计、分类及联动状态。

会议分析准备页顶部和空状态提供“查看时间轴演示”，打开由 `MEETING_TIMELINE_DEMO_TASK_ID` 标识的独立记录；进入演示不改写准备页已添加的资料或配置。也可经“任务中心—带演示标记的会议纪要分析记录—查看结果—会议议题”进入。独立演示资料用于展示同日多会议、跨会议同类事项、参会和列席人员、不同金额及未知日期等情况，不能冒充真实模型分析或正式审计事实；结果页保留演示标记，与用户记录区分，不覆盖已有任务。时间轴复用既有结果行、来源和配置快照，未改变原始Vue或后端请求结构。真实聚类、正式分析结果、任务队列与SSE仍以后端联调为准。

## 2026-10-23：提示词选择与配套规则复核

原工具主要从提示词库选取对应功能、对应阶段的提示词，不能统一包装成“分析方案”“使用方案”。普通选词、编辑提示词、另存个人提示词和完整配置导入、导出分别表达；选词不等于运行分析，另存不等于应用。此节为提示词相关表述及覆盖范围的最新口径，优先于此前迭代中涉及整套方案的说明。

### 配套规则与覆盖确认

风险点树、工程字段及判定规则、两表对比配置、招投标检查规则是原工具合法能力，不因取消“方案”表述而删除。界面采用“选择提示词”“提示词内容”，并在有配套规则的阶段显示“风险点”“字段与判定规则”“字段匹配与判定规则”或“检查规则”。选择后的变化限于当前阶段及其原有配套内容，不加载其他工具或阶段的完整配置。

切换会替换已编辑内容时，确认窗口直接列出影响，例如“将替换本次重复项目的字段、权重、规则和补充提示词”；取消时恢复原选项和草稿。纯文本阶段切换仅影响当前正文，不得声称会替换字段或参数。风险点树变化后按原有效ID口径处理勾选，不保留不存在的风险点。

### 保存、旧记录与历史任务

- “另存个人提示词”只保存当前阶段的名称、正文、功能类型及该阶段原有配套规则；不带入已选资料、附件、任务名称备注、其他阶段或结果。保存后是否采用以明确操作为准，不能暗中切换。
- 旧个人记录若以整套配置保存，按工具和阶段读取对应提示词与相关规则；不能将旧 `config` 整体赋给当前工作区，也不能因新结构不同而删除旧记录。
- 历史任务始终读取执行时快照；提示词库改名、删除、更新均不得回写历史。缺少原提示词记录时仍显示快照正文和已记录名称，不用当前默认提示词补齐旧任务。
- 完整配置JSON导入、导出单独置于低频区域，清楚标注“导入配置 / 导出配置”。保留原校验、确认和回读能力，但不放进普通提示词选项，也不称作选择分析方案。
- 原始正式接口ID与本地个人记录ID区别处理。自定义正文不能冒用未修改的库记录ID；请求仍遵循原工具支持的ID和正文契约，不由界面文案推导新协议。

## 2026-10-23：结果页调整后再分析

11项工具的结果页提供“调整后再分析”，点击只将本次实际资料与配置带入可编辑准备草稿；用户确认提交后才生成新记录，原任务只读保留，来源记录可追溯。任务中心仍保持“查看结果 / 任务信息 / 导出数据”三项纯文字操作。运行中停止、部分失败重试、后续报告生成及待摊费计算继续沿用各自原流程。

复制范围包括各阶段提示词及配套规则、项目与单位角色、双表来源和名称、词云实际执行词表及下次停用词、会议后续风险要求；待摊费旧基数只用于下一阶段预填，不自动复用旧计算结果。准备预览必须属于本次范围，招投标不继承其他草稿残留的未分配资料。新的编辑草稿与历史访问、原任务结果分别保留。

`attachment-draft.js` 统一附件读取和写入：任务界面读取执行时 `task.attachments`；从历史进入的准备草稿采用独立 `attachmentOverrides`，原任务范围内未记录的关联明确为空；新添加主文件先复制资料库当前关联，再独立修改；普通资料库和没有独立草稿的初始编辑沿原关联行为。主文件的新增、移除、撤销、附件选择候选排除及新任务快照使用同一口径，不通过回写 `file.attachments` 还原历史，从而保留资料库、旧任务与新任务各自的关联。相关定向验证见 `tests/browser_attachment_draft.py` 和 `review/attachment-draft-checks.json`，具体结论以实际检查记录为准。规范见[26 · 结果页调整后再分析](../UI界面规范/26-结果页调整后再分析规范.md)。
