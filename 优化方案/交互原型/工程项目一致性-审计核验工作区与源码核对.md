# 工程项目一致性：审计核验工作区与源码核对

更新日期：2026-10-23。原始 Vue 文件未改动；本次仅更新交互原型并由主任务发布至现有 Sites。

## 使用顺序

1. 添加本次项目台账。每张台账分别比较自身记录，文件下方明确显示比较列已对应或缺失的具体列名；不把不同台账合并成一次跨文件检测。
2. 分别设置重复项目与主子项目。“重复项目 / 主子项目”页签只切换正在浏览的配置，两类分析始终同时执行。各自独立选择系统或个人提示词、设置候选判定分数、比较字段与评分规则。
3. 执行后按候选类型、来源台账、匹配方式及关键词查找结果。进入“原因与源行”同时对照两条记录、实际字段评分与权重，按需打开原始台账。
4. 导出保留两类候选、动态字段名称、真实返回分数和完整来源行；需要调整时沿用配置再次分析，旧任务保持只读。

## 原代码关系与保留方式

核对 `EngineeringProjectViewer.vue`、`engineeringProject/ConfigPanel.vue`、`SingleTableFieldMappingEditor.vue`、`engineeringSingleTableConfigHelpers.js`、`engineeringProjectResultMapper.js`、`engineeringProjectExport.js`。

| 原功能 | 本次处理 |
| --- | --- |
| 重复项目与主子项目两个独立提示词和配置块 | 两页签分别浏览，明确说明同时执行；提示词库、编辑、另存个人提示词及配套规则替换确认保持共用逻辑。 |
| F字段映射、比较方式、预筛阈值、权重、评分规则 | 主要清单显示比较内容、列名、方式及权重；单字段弹窗保留完整编辑，权重用百分比表达，内部仍使用0–1。 |
| 判定阈值0–5，预筛阈值0–1 | 界面分开表述候选判定分数与字段预筛，金额差异提示比例含义；重复检查不能使用“金额大于”。 |
| 权重正数之和应为1（允许0.02偏差） | 按源容差校验，零权重字段不强制提供评分文本；逐份台账仍必须包含本次映射列。 |
| 删除字段须连续重编号并同步规则 | 同步字段权重、评分规则、硬规则、否决规则及分期字段引用，取消删除不应用。 |
| 原配置包含辅助列、别名、仲裁等扩展字段 | 在 `singleTable` 中完整保留；派生逻辑字段名、读取列及最终请求按当前映射更新；未在当前源界面提供编辑器的扩展参数不擅自清空。 |
| 结果包含模型比较与编码精确匹配 | 区分模型分数与24位编码匹配。原代码为编码匹配记录固定值5，界面说明该值不来自模型评分，不将其当成置信度。 |
| 模型结果动态字段及源行 | 结果字段标签优先使用返回快照；0、false、对象及原始行完整保留，不裁剪成固定三个字段。 |
| 来源与历史任务 | 单条候选的显式来源必须全部属于本条正在处理的同一台账；任务内另外一张表也不能混入。查看/下载分别检查权限，历史只读，沿用配置生成独立草稿。 |

## 请求对齐

工具局部执行快照对齐 `buildEngineeringExecConfig`：`exec_mode=custom`，`custom_config.mode=engineering_project`，保留两个提示词、总体阈值与两类阈值，以及 `duplicate_detection / parent_child_analysis`。

每块保留 `field_mapping / logical_field_mapping / columns_to_read / auxiliary_columns / column_aliases / prescreen_config / llm_config`。比较字段原有的跳过双空、是否计入预筛、数值规范化设置优先保留；最终阈值统一大于等于。更改表格展示页、检索或结果筛选不改变实际请求范围。

## 验证与边界

`tests/browser_engineering_workflow.py` 核对两类配置隔离、单字段保存与取消、原配置扩展字段保留、字段删除联动、逐文件缺列、1000字段分页及完整请求、原始结果块、动态列、模型零分、false、编码匹配、源行、导出、任务外和同任务跨文件来源隔离、历史只读与调整后再分析。覆盖1366×768、1024×480、390×600界面。

本地演示仍不执行真实模型或正式台账比对。示例候选只用于验证交互；生产比较、模型评分与真实文件服务仍须按原接口联调。
