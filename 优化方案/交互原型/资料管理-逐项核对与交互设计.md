# 资料管理：逐项核对与交互设计

更新日期：2026-10-18。范围为资料管理、目录、上传解析记录、附件、正文检索，以及资料带入分析工具。其他工具的配置和结果流程沿用上一版。

本轮已修改可交互界面，并更新原站点的资料管理页。原始 Vue 前端、截图和会议纪要未修改。内网地址 `172.16.0.106:19535` 在当前环境连接超时，因此本次核对以提供的原前端和截图为依据，不声称已登录原系统实测。

## 一、审计业务判断

资料管理首先要回答：我在哪个项目或空间、这份资料能否用于分析、已选范围究竟是什么、能否回到原件。它应支持“整理资料—选择范围—分析—核验”的连续工作，而不能仅作为一个文件上传列表。

本轮的处理原则：

1. 目录定位在左，资料整理在中，分析入口在右。文件夹和文件同层展示，多级目录不打平；面包屑始终保留当前位置。
2. 首屏保留一行标题及操作，不再放大幅介绍。搜索、筛选、范围、更多放在同一工具行；已选摘要紧邻文件表。
3. 文件名称为第一视觉重点，状态为第二重点。所有者、上传时间默认显示；最近查看、大小、位置可在“设置显示列”中选择。列过多只让表格内部横向滚动，行操作固定在右侧。窄屏在尚未设置菜单偏好时自动收起主菜单；手机目录改为抽屉，文件名称与状态优先显示，完整操作从详情进入。
4. “取消选择”只改已选范围；“移除关联”只解除附件关系；“删除文件”需要确认。文案和反馈区分三者。
5. 未解析、解析中、失败和未关联原文的资料仍可在资料管理勾选，以便批量处理；进入分析工具前列明不能纳入的文件和原因，由用户确认剩余范围，不静默过滤。
6. 重命名、移动保持文件标识；覆盖同名文件保留旧版本用于已有任务核验。删除资料时清理尚未执行的草稿范围，保留已有任务引用。
7. 引用目录只读，取消引入只移除引用；源资料保留。权限、目录来源、项目角色应决定操作可用性。
8. 各工具内“添加资料”入口保持可见，包括历史结果和宽屏结果。此次未改动字段、提示词、规则、模板与任务快照逻辑。

## 三、后台少改的实施边界

当前站点为独立前端实现，没有连接内网业务后台。其权限、授权和管理员设置用于交互核对；不能替代真实认证、授权、OCR 服务或 Redis 队列。上传的原文件保存在当前浏览器，解析使用浏览器中的文档解析能力。新建、重命名、移动、引用、删除、授权的状态在本地保存。

生产接入需要保持以下约束，而不能照搬本地数据结构：

- **真实标识**：保留 file_id、folder_id、parent_id、ref_id 和项目/机构/用户 ID；本地的中文空间名和路径只用于界面定位。目录重命名不应批量改写真实文件 ID。
- **空间根节点**：原 loadFileList（5080 后）在项目/个人空间未选目录时不拉全空间文件；公共空间才有 by-space 聚合逻辑。上线时将默认定位落到现有可访问文件夹，根级只展示已有子目录；不要为了本地首页的根级资料展示，新增重型全空间查询或改变原接口语义。
- **项目节点差异**：年度、单位、项目、小组、普通目录不能视为同一种文件夹。沿用 6094–6154、6235–6458 的类型和 user_permissions 判断；项目/小组可管理、引入不等于可直接上传，引用/OSS 目录保持只读，机构根目录限制新建下级。按钮按后端能力控制。
- **权限与身份**：独立界面里的默认管理状态不是生产授权依据。普通用户不能通过界面状态取得超级管理员能力；用户/机构选择应替换为现有组织树和真实用户选择，不直接提交显示名。分权、项目绑定、机构绑定按原权限分别控制。
- **原件与解析**：正式下载走现有签名 URL；OCR、DOC/WPS/PPT 等转换仍用现有服务，不因本地解析格式有限而缩小正式系统支持范围。扫描 PDF 本地无法识别会明确失败，不编造正文。
- **上传恢复**：继续复用原 uploadCache、分片上传 ID、Redis 目录上传会话、哈希检查、已完成文件跳过、覆盖冲突回执。浏览器保存原件是当前站点的交互能力，不应取代服务端恢复。
- **记录状态**：原上传服务有 uploading、pending、processing、done、failed、stuck 等状态，正式记录应直接映射这些状态和更新时间，并保留两类 OCR 队列。当前本地只产生实际可验证的未解析、解析中、完成或失败，不制造服务器积压和 OSS 处理进度。
- **排序与分页**：优先沿用现有排序方式；如果接口不支持新增排序字段，就保留原有上传/查看排序，不在一页数据上伪装全量排序。总数来自接口，不累加当前页推算。
- **历史可追溯**：本地保留旧版本对象可验证覆盖后的查看行为；正式接口 overwrite 会产生新 file_id（原 API 注释已说明）。联调时必须确认旧任务是否仍可取得原始内容，不能仅依赖前端保存引用保证审计证据留存。
- **动态配置**：空间、解析状态、工具清单继续由现有字典和权限服务提供；当前站点的三类空间、11 项工具是已有业务的交互呈现，不作为未来扩展上限。

因此，这轮可以直接用于前端评审和操作核对；生产上线还需用既有服务做权限、分页、上传恢复、原件预览与历史版本联调。本轮没有修改任何后端逻辑，也未冒充完成上述生产联调。
