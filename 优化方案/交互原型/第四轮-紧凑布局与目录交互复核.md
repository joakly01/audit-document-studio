# 第四轮：紧凑操作栏、多级目录与业务入口复核

日期：2026-10-18。本说明补充并优先于第三轮中与之冲突的布局描述。原型地址仍为同一个私有站点。

## 这轮解决什么

1. 工具页移除单独的全局顶栏、长简介和单独步骤行，合成 **56px单行操作栏**。左侧工具名和图标，中间简短步骤，右侧任务状态、帮助、任务中心及主操作。手机允许两行，避免挤压文字。
2. **执行统一在右上角**。读完资料和右侧配置即可执行；左侧不再把添加资料、预览与执行混在一起。运行时同一位置为停止，费用第一阶段为提取计费约定，待填写时为填写基数，完成后为复制配置新建。结果筛选、报告、导出仍靠近结果。
3. 资料管理、添加资料、本次资料树都采用一致目录语义：**同层可有文件和文件夹**，可多级嵌套，支持根目录文件、空目录、面包屑返回、展开/收起、搜索、跨目录与跨空间保留选择。
4. 本级与递归不混用：列表范围“仅本级 / 含子文件夹”；加入目录时明确“仅本级文件 / 本级及所有子文件夹”。本页全选只勾选本页文件，选择所有页只选当前搜索范围内的文件。预览、搜索、收起目录均不改变执行范围。
5. 工具保持不同业务图标，增加稳定的低饱和识别色。颜色仅作辅助，名称、动作、状态仍有文字。首页保留一行工具用途，工具工作页去掉重复简介。

## 从左到右、从上到下的操作顺序

| 区域 | 职责 | 本轮约束 |
| --- | --- | --- |
| 左导航 | 选择业务工具、返回资料管理和任务中心 | 图标与工具名称一致；窄屏图标保留名称提示 |
| 顶部 | 确认当前工具、阶段，执行全局主操作 | 所有11工具位置一致，不因模板较长而滚走；不在多处重复执行按钮 |
| 左侧本次资料 | 添加、浏览、查找与管理范围 | 文件夹展开与文件预览不等于选择；移出有撤销，原件保留 |
| 中间工作区 | 原文预览或专业结果 | 原文与结果的用途明确；会议、招投标、两表保留专业结构 |
| 右侧配置 | 模板、业务参数、提示词及高级配置 | 常用项直接可见，复杂编辑进入面板；运行后读取快照 |
| 弹窗 | 完成一次独立编辑或选择 | 右下确认、左侧取消；预览后返回同一个资料选择暂存清单 |

桌面1366×768、1280×720、1024×600实测：工作区从56px开始；准备页执行按钮下边缘44px，保持在视口内。上一版为120px，回收64px。390宽度下顶部两行约90px，主操作仍可见。

## 目录模型与后端最小改动

- 原型中的目录路径用于演示；空间＋完整路径区分同名目录，文件以ID去重。示例资料调整了路径以覆盖根目录、三层目录、同层文件/文件夹场景，原始业务资料未移动。
- 生产回迁应继续使用原folder_id/parent_id、树节点、SELF/SELF_AND_DESC、recursive、排除文件/目录、分页及权限字段。不能把目录选择永久展开成当前已加载的几页文件。
- UI最终范围必须映射到各工具自己的builder；尤其会议与通用builder不能假设选择优先级相同。目录懒加载、并发数据变化、权限失效及大批量任务需接现有服务验证。
- 合同开关映射既有button参数；保留text与text_2两类结果及文本回退，沿用原规则校验与类别判断。原型`configurationFragment`仍只是字段核对片段，不是可直接发给后台的完整请求。
- 会议原源码通过`importAnalysisResultAPI`支持JSON/XLSX，组件导入结果再转换为meetings/clusters。当前摘录中缺少该API文件，实现时保留原调用；不要改成全量前端解析Excel。源代码也提示导入结果可能没有问答向量索引，因此不能因导入成功就声称真实深度问答已经可用。
- 此轮仅修改独立原型，未改动提供的原Vue源码、任何后台服务或原始截图/纪要。

## 可操作与待接入的界限

**本轮可操作**：混合目录浏览、目录搜索、同层/递归选择、预览返回、跨空间暂存、空目录创建、资料树管理/撤销；右上统一执行/停止/续填；合同自动分析配置与示例结果；会议JSON导出再导入及错误校验；前几轮已有配置编辑与流程。

**仍需原服务**：真实上传/OCR、模型评分与提示词执行、合同自动分析算法、会议Excel导入/真实结果结构转换/向量索引、真实模板及词库持久化、报告格式、精确页码定位、权限与后台长任务。原型保持虚构数据和本地演示标识。不能据“按钮齐全”认定业务后台已验证。

正式回迁前，逐项对比改前改后的资料ID/目录范围、模板ID、阶段配置、数值量纲、合同button、原结果字段与导出范围。功能目标仍为整理材料、发现和核验线索，不自动认定审计事实。
