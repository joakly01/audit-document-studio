# 风险点大量选择交互核对

更新日期：2026-10-23；资源版本：20261023.66。

本轮将右侧风险点长清单改为“已选数量 + 分类概况 + 选择风险点”，在独立窗口集中进行分类浏览、检索、分页和批量勾选。保留风险点新增、单项编辑、删除确认、检查说明及原有必填和重名校验。小屏使用分类下拉框，列表独立滚动，确认操作固定在底部。

原前端 `前端代码/views/document-mining/RiskPointAnalysisPrototype.vue` 第319行起使用可检索树选择，第1470行附近将父节点选择展开为叶节点，第1672行起由提示词配套配置恢复风险树与选择。本轮沿用这一业务关系：分类勾选展开至实际风险点，提交继续保留叶节点的编号、路径、名称和原有检查方式；提示词未配置风险点时保持空态，不回退固定内置清单。

分类整组选中包含全部下级；本页只选当前页；“选择全部页”和“取消当前范围选择”以当前分类、检索条件和全部/已选视图为范围。各分类间选择累积，不因翻页、搜索或分类切换丢失。新增、编辑、删除和勾选先写入弹窗草稿，确认后才应用到本次配置，提示词库及历史任务保留。

历史任务默认查看本次已选风险点，可查分类和完整说明，不能勾选或修改。风险分析提交、逐资料核查、部分失败重试、结果状态、原文依据和导出链路不变。

实现为 `dist/risk-selection.js` 与 `dist/risk-selection.css`。风险配置栏直接生成紧凑界面，避免先构建再隐藏旧版完整清单；选择窗口默认每页20项，支持50、100项，只创建当前页行。中文输入沿用现有输入法保护，勾选保留列表滚动位置。

交互验证见 `tests/browser_risk_selection.py`、`review/risk-selection-checks.json`，并回归提示词局部替换、会议与风险业务流程。正式后端风险点配置、权限及执行接口仍需按原契约联调，演示交互不代表新增了服务端风险点库。
