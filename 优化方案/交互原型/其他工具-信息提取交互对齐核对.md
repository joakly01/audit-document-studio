# 其他工具与信息提取对齐：原功能核对

2026-10-19。本轮修改优化后的交互前端，原始 Vue 目录未改写。

| 工具 | 本轮核对的原源码 | 必须保留的业务 |
| --- | --- | --- |
| 词云 | views/word-cloud-analysis/Index.vue，buildWordCloudExecuteFileIds.js | 本次停用词/用户新词、词库增改导入冲突处理、词频与来源、展示数量和导出 |
| 主题 | ThemeAnalysisViewer.vue | 基础提取与归纳两阶段、独立提示词、阶段结果与失败重试 |
| 时间轴 | DemoAudit/timeline-analysis/TimelineAnalysisViewer.vue | 文档事项日期、事件来源、未取得日期、提交名称及任务回看 |
| 风险点 | document-mining/RiskPointAnalysisPrototype.vue | 风险层级与选中项、两种遍历顺序、匹配/未匹配/资料不足、证据与导出 |
| 会议 | DemoAudit/meeting-minutes-analysis/index.vue | 常规结果、议题归类、筛选、风险报告独立要求与执行、问答及结果导入导出 |
| 合同 | file-manager-code/ContractViewer.vue、components/contract/ConfigPanel.vue | 类别、合规/完备性规则与提示词、附件合并、自动分析、来源与报告 |
| 招投标 | DemoAudit/bidding-analysis/BiddingAnalysisViewer.vue、components/BiddingAnalysisRulePromptPanel.vue、utils/biddingAnalysisPromptConfig.js | 项目及单位归组、招标/投标/联合三类、对应独立阶段要求和证据结果 |
| 待摊费用 | document-mining/PrepaidExpensesPrototype.vue | 费用类型、计费约定提取、基数输入及计算，不将全部合同固定为一个费率 |
| 工程项目 | file-manager-code/EngineeringProjectViewer.vue、components/engineeringProject/ConfigPanel.vue | 重复/主子项目独立配置、字段权重/预筛/阈值/最少匹配字段与原行核对 |
| 两表关联 | AssociationDegreeTwoTables.vue | 两表独立业务名与选择、字段映射、标准/批量、每行及全局上限、硬规则、四项锁定、来源行 |

公共逻辑参照 OcrLeftSidebar.vue、useSimpleOcrLeftSidebar.js、useOcrSidebarAttachment.js、AttachmentSelectDialog.vue 与 buildToolBatchExecutePayload.js。批量执行的目标是全部已添加主文件，不因左栏查找或当前预览而缩小；附件关联与主文件选择分开。

本轮统一准备页面；既有 configurationFragment、校验、run、taskArea 和各工具结果组件继续承担业务处理。两表的大表读取仍有分页上限，不能为预览一次性加载全部行。招投标归组编辑收纳在独立管理弹窗，可添加项目、投标单位、指定文件角色并增删归属。

默认工具入口与历史地址分离：`#tool/<tool>` 为准备配置，`#tool/<tool>/<taskId>` 为任务回看；各自草稿保存资料、项目、表槽和参数。历史结果本身不因导航被改写。

接入边界：优化工程仍是独立前端。原 Vue 的逐文件二次配置/执行、正式 AI 请求、后台队列与权限接口应沿用原服务联调；本轮没有把本地进度驱动或固定数据视为后台能力，也没有更改原 API 定义。已存在的专用结果与参数编辑继续可用；原 Vue 中尚未移植到优化工程的逐文件二次执行不能宣称已实现。
