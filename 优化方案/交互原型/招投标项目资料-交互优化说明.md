# 招投标项目资料配置

更新日期：2026-10-24。

原系统 `BiddingAnalysis.vue` 以项目包含单份招标文件、多家投标单位，每家单位可以关联多份投标文件。此次保留这个归属关系及执行参数，重点改善项目和文件的配置过程。

- Step 1 使用“添加项目资料”，右上方“添加项目”。项目清单直接显示名称、招标文件数、投标单位数、投标文件数及当前缺项；展开一个项目进行操作，不再依赖下拉框猜测当前归属。
- 项目内区分“招标文件”和“投标单位”。投标单位可以独立展开、收起，显示名称和文件数。文件名称可查看原文，移除仅取消本次关联。
- 添加项目、添加投标单位时先填写名称，取消不创建空记录。修改名称使用同一小弹窗，不在资料清单中铺满输入框；新增后定位到下一步文件选择按钮。
- 空的招标区直接显示“选择招标文件”，已选时提供“更换文件”；单位内使用“选择投标文件／管理投标文件”。文件弹窗明确所属项目和单位，保留仅解析完成可选的提示。招标文件单选替换、投标文件多选及跨页选择规则不变。
- 单位较多时保留按单位／文件名称查找和每页10家单位的分页。查找、分页、项目切换和折叠仅影响浏览，所有已配置项目继续参与提交。
- 从资料库带入的待分配文件继续支持指定项目和文件角色。已有角色移除、项目移除及撤销逻辑保持，不删除资料库原文件。

执行仍使用原 `projects / tender / bidders / files` 数据结构，通过 `configurationFragment` 映射为项目名称、招标文件和各投标单位文件；三种分析模式、提示词绑定的全部规则、只读任务信息及结果页面保持。

验证见 `review/bidding-materials-checks.json` 和 `review/bidding-workflow-checks.json`：覆盖取消、必填、中文输入、名称修改、单选替换、多选、归属分配、折叠状态、撤销、27家单位、三尺寸、1000条规则、实际提交和历史快照。均通过，无页面脚本错误。仅更新 Sites。
