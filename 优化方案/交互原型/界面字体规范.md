# 界面字体规范

> 共用规则已归并至 [UI 界面规范](../UI界面规范/01-UI界面规范.md)。主操作栏单行收纳；本文件保留字号专项的实现与验证说明。

本规范面向审计业务系统的屏幕阅读，统一业务页面、工具配置、结果、资料选择与检索弹窗。导出的公文版式按其独立模板处理。

| 层级 | 字号 | 使用位置 |
| --- | --- | --- |
| 页面标题 | 22px，部分页面 20–24px | 资料管理、任务与模板页面标题 |
| 工具名称 | 18px | 紧凑业务操作栏 |
| 弹窗标题 | 20px | 上传、编辑和核验弹窗 |
| 区块标题 | 18px；密集面板16px | 本次资料、分析设置等 |
| 正文及主要交互 | 16px | 文档正文、表格文件名、目录、导航、按钮、输入与配置字段 |
| 辅助文字 | 14px，不再向下缩小 | 表头、状态、时间、容量、路径说明、提示及元信息 |

字体优先使用微软雅黑、苹方和 Noto Sans CJK SC；无上述字体时使用系统无衬线字体。正文行高约 1.6，原文阅读区约 1.9；控件文字行高 1.5。次要信息提高灰度，避免小字浅色叠加。按钮和表单控件最小高度 36px。

字体由 typography.css 的统一变量控制：--font-body、--font-caption、--font-section、--font-page。已有样式中的小字号已替换为统一变量，包括各工具、窄屏规则及旧页面；内联输入文字同步改为 16px。文件类型标识扩大容器，避免字号变大后挤压。

低分辨率不回退到小字号：目录支持滚动；表格调整列宽并在自身区域滚动；主操作栏与资料工具栏必须保持单行，次要操作和筛选随可用宽度进入“更多”；表单字段、配置正文与说明可正常换行。保持既有固定列和文件操作，不恢复已取消的显示列设置。菜单保留折叠与展开。

本轮浏览器检查资料管理、任务、模板与 11 项工具，在 1366×768、1024×768、390×844 下共 42 个页面状态：无低于 14px 的可见文字、无整页横向溢出、无页面脚本错误；并检查添加资料、文本检索弹窗与已加载资料的原文阅读。结果及截图见 review/typography-review.json 和 review/type-*.png。原始 Vue 代码及后台接口均未修改。

2026-10-19核对：新工作区文件类型标识恢复14px；各工具主操作在窄屏仍为16px、≥36px，辅助入口通过更多收纳。最新覆盖层为ui-conformance.css/js，当前验证范围见UI规范第16号核对记录，历史42状态记录不作为全量认证。
