# 审查问题与实施验收

日期：2026-10-25。优先级用于安排研发，不将“未取得证据”直接判定为已有后端缺陷。

## 1. 结论与证据等级

| 等级 | 含义 | 适用内容 |
| --- | --- | --- |
| A 当前直接证据 | 本轮读取代码或重新执行浏览器检查 | 实际标题、入口、布局、任务动作、文字对比度、源码调用 |
| B 历史专项证据 | 之前针对该原型形成的测试记录 | 大批量、长文档、连续核验、再次分析和工具专项；未宣称本轮全量重跑 |
| C 待真实服务验证 | 原型和前端调用不足以证明 | AI质量、后台持续运行、权限、队列、单位和跨用户持久化 |

`evidence/current-review.json` 覆盖11工具×3尺寸共33个准备态，并另查公共页面和可用已完成记录。结果页不展示准备态资料栏，打开历史结果未改写快照。待摊费用没有现成已完成样例，本次引用其既有两阶段专项，没有为凑齐数量创建新任务。

UI 专项另查三种尺寸、任务中心的三个文字操作及新增辅助文字颜色。无页面横向溢出不等于已通过完整可访问性、屏幕阅读器或移动业务验收。

## 2. 需处理的问题

| 编号 | 优先级／性质 | 发现与影响 | 处理及关闭条件 |
| --- | --- | --- | --- |

| R03 | P1 维护风险 | 多层脚本覆盖相同函数，源码仍有历史入口文字 | 正式 Vue 按职责组件和工具适配器收敛；状态来源唯一，不继续依赖覆盖顺序 |
| R04 | P0 契约确认 | 前端摘录不完整，部分专用接口仅见组件调用 | 补完整工程/API资料；关键调用具有请求、回执、错误和结果样例 |

| R06 | P0 选集确认 | 原会议载荷解析状态较宽，新选择器只允许解析完成 | 前端、目录展开与服务端资格统一；全部页不带入不符合条件或失权文件 |
| R07 | P0 状态确认 | 专用阶段、历史工具类型兼容及停止语义不能由原型决定 | 映射真实状态与类型；确认停止／删除／重试能力，不串工具、不误判完成 |
| R08 | P0 接入工作 | 当前有模拟执行、本地持久化和演示输出 | 正式环境替换服务适配；创建、查询、结果、导出、刷新均来自真实服务 |
| R09 | P1 能力确认 | 人工意见仅在浏览器保存，指纹不能代替长期结果 ID | 需要协作时接真实身份、稳定 ID 与最小保存服务；原输出保持不变 |

| R12 | P1 可用性缺口 | 已有自动化检查，缺少真实审计人员首次使用观测 | 用具体业务任务观察理解和误操作，改进后复测 |

## 3. 不应回退的决定

| 范围 | 必须保持 |
| --- | --- |
| 资料管理 | 当前目录、正确空间路径、统一上传入口、解析状态明确；文件／文件夹选择位于上传弹窗 |
| 资料选择 | 本页／全部页明确，反馈统一顶部；解析完成且可分析；中文组合输入稳定 |
| 信息提取 | 模板默认不选，本次字段可编辑并另存个人模板；逐资料关联附件；移除不删除源文件 |
| 通用准备页 | 动宾步骤、无收起原文、紧凑页头；查看原文不是执行前置条件 |
| 复杂工具 | 项目／单位／文件角色、合同分类规则、字段映射保留，不强行三栏 |
| 提示词 | 系统默认与个人可选；公共／机构／个人分类；正文编辑优先，只影响当前环节 |
| 结果 | 不显示准备态资料清单；再次分析先编辑再提交新记录，旧历史保留 |
| 任务中心 | 查看结果、任务信息、导出数据三项文字操作，无前置图标；按工具开专用成果 |
| 低频入口 | 移除工具设置导入／导出；词库和独立提取模板管理专用能力保留 |
| 会议／风险 | 时间轴、议题聚类和筛选保留；无时间轴演示入口；风险启动称开始分析 |

## 5. 端到端验收

| 场景 | 操作 | 必须观察到的结果 |
| --- | --- | --- |
| 首次提取 | 添加两份资料，设置字段，提交、查来源、导出 | 动作可找到；模板不误选；实际字段和资料与提交一致 |
| 跨目录选择 | 选本页、当前筛选全部页，切目录和查找，取消部分 | 数量、范围、排除项一致；分页和预览不影响执行 |
| 资格变化 | 已选后失权或解析失败，再提交／查看原文 | 明确不可用项，服务端重验，不静默扩大或泄露 |
| 中文输入 | 连续拼音输入目录、文件和提示词名称 | 组合期间不丢输入、光标，提交后更新查询 |
| 本工具结果 | 立即／排队执行后留当前页，离开再从记录返回 | 状态真实，同一任务结果，不强制转任务中心 |
| 超时断线 | 提交超时、轮询失败、刷新、重复点击 | 未确认不报成功，可找到原任务，不产生重复或伪完成 |
| 失败恢复 | 部分失败后重试 | 成功结果保留，仅约定失败对象重试 |
| 再次分析 | 修改历史资料／提示词后取消或提交 | 取消不建任务；提交新记录；旧结果及快照不变 |
| 大量规则 | 1000条规则检索、分页、选择及详情 | 显示筛选不改变执行范围，隐藏页规则不丢 |
| 会议 | 时间轴、聚类、人员／日期／金额／关键词筛选及后续风险问答 | 会议与议题关系正确，筛选可清除，阶段依赖明确 |
| 招投标 | 多项目、多单位、招标替换、投标多文件、切模式 | 资料归属正确，未分配项不误执行，不适用与失败区分 |
| 合同 | 自动／指定类别，分类规则、附件、证据、报告 | 类别规则正确，来源可核验，报告失败保留检查成果 |
| 费用 | 六类按支持范围取样，填写不同基数、继续计算 | 单位一致，同一任务续算，由真实服务计算 |
| 工程／两表 | 表头变化、缺字段、边界阈值、角色及源行核对 | 映射不静默错位，原评分量纲保留，二次筛选可恢复 |
| 来源／导出 | 多来源、无页码、过期链接、不同导出范围 | 降级明确，范围、单位、来源及缺项说明完整 |
| 窄屏／键盘 | 1366×768、1024×480、390×600，Tab、Esc、面板切换 | 操作可达，无页面级横向滚动，焦点返回触发位置 |

真实答案正确性需另用人工标注验证，不能仅检查结果非空或下载成功。

## 6. 如何衡量提升

本轮不宣称节省固定比例时间。建议用同一资料集与任务对照测量：

| 指标 | 口径与用途 |
| --- | --- |
| 首次任务完成率 | 无他人代操作而完成选资料、执行和看结果的用户比例，评估易懂程度 |
| 范围错误率 | 实际资料、角色或排除项与任务要求不一致的比例，评估选集可靠性 |
| 来源核验耗时 | 从选中结果到找到足够原文上下文的时间，评估连续核验 |
| 再次分析正确率 | 成功生成新记录且旧记录完整的比例，评估按钮含义和快照保持 |
| 故障恢复成功率 | 断线、部分失败和阶段中断后正确恢复的场景比例 |
| 渲染／输入响应 | 指定硬件和规模下首屏、分页、输入及原文切换的P50/P95，前后端分开测 |
| 业务结果质量 | 人工标注下的提取准确性、遗漏、误报和来源支持率，独立于UI体验评测 |

目标值在取得现网基线、文件分布和硬件信息后确定。模拟数据不作为生产容量承诺。

本轮提供总方案、模块对照、UI规范、后端清单、对标与整改验收，并生成阅读版和可编辑版。应用源码和部署保持现状。
