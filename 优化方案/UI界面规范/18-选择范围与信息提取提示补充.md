# 选择范围与信息提取提示补充

2026-10-21，沿用现有字体与嵌入布局规范。

- “选择全部页”统一在表格上方，与当前范围和选择状态一起呈现；表头复选框标明“本页”。表格下方只保留翻页及整体已选数量等摘要。
- 资料管理、添加资料、选择台账共用“包含下级文件夹”复选框。默认查看当前文件夹，勾选后扩大到全部下级文件夹；放在当前目录下方、文件列表上方，使用普通白底文件显示选项，与右侧跨页选择操作区分。切换显示范围保留已有选择。
- 信息提取左侧说明为“点击‘添加资料’选择文件，下方为已选资料”；底部显示“已选 N 份资料”，数字强调；超过50份时追加“本页第1–50份”等当前显示范围。查找时追加匹配数量，清空查找后恢复简洁摘要。
- 解析完成、文件类型和分析权限的选择限制放在添加资料弹窗说明与不可选行提示中。
- 提取模板标签使用“提取模板”，去掉“可选”；默认不预选。空配置说明“选择模板载入字段，或点击‘添加字段’自行配置”，至少配置一个有效字段后才能开始提取。
- 上传操作归入添加资料弹窗的查询工具栏，范围与选择栏专注于范围切换和跨页选择。

验证：跨范围选择保持、页选与全量选择、中文输入、模板与自定义字段入口、1366×768／1024×480／390×600布局。见交互原型 `review/selection-guidance-checks.json`。

目录与清单翻页补充：

- “当前位置”统一为“当前目录”，项目路径保留“项目空间 / 项目名称 / 下级目录”。长路径优先保留空间名称与当前文件夹，中间层级收为省略号；点击可查看完整路径并跳转上级，悬停也提供完整目录。
- 已选资料翻页使用文字“上一页／下一页”和“第N / M页”，保留页码输入与当前文件定位。单页最多50份，翻页只切换清单显示，已选总量及当前原文保持。

本补充单独交付，既有v1.3 PDF不包含本章。


已选资料的统一呈现：

- 每个工作场景保留一个主要清单位置。资料管理集中在表格底部“已选文件”入口；各分析工具集中在左侧资料清单，底部显示总数和必要的当前显示范围。
- 工具页顶部不重复资料和字段总数，右侧配置区不再重复资料总数。字段数量仅在字段列表标题表达；窄屏资料页签保留数量，方便切换面板时识别处理范围。
- 添加资料弹窗右侧统一为“已选资料 N 份”，只在此处显示总数；底部使用“确认选择”，不再重复数量。该清单包含先前已添加的资料，确认更新本次工具清单，取消保留原选择。
- 表格上方仅表达当前范围的本页／全部页操作及局部选择状态，不再叠加跨目录总数。其他目录的选择在完整清单中统一查看。全选状态只由“已选全部页（N份）”表达一次。
- 附件、招标/投标资料、两表对照保留明确业务名称与角色；附件选择不等于主资料选择。任务提交前的范围核对、任务执行资料快照与进度数量继续保留。
- 资料库的跨目录勾选、工具本次分析资料、弹窗未确认选择三者语义不同，不共享可变选择状态；简化显示不能破坏取消、权限复核、翻页和附件关联逻辑。

验证记录：交互原型 `review/selection-homes-checks.json`；覆盖11种工具、取消与确认、跨目录全选、51份清单翻页、逐项移除及低分辨率布局。
