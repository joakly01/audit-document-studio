# 大批量与长文档交互补充

2026-10-21，沿用v1.3的字体、按钮、图标与紧凑工作区规则。

1. 显示范围、选择范围、执行范围、导出范围必须独立。分页、过滤、预览切换不改变已经确认的主文件集合。
2. 少量资料保持简洁；超过50份的工具资料清单分页。分页位于清单内部底部，不额外增加整页顶部区域。
3. 显示完整执行总数；查询时另显示匹配数。提供“定位当前”，使当前原文可回到对应清单行。
4. 查找时显示匹配目录中的文件，中文输入法组合期间不重绘输入框。长正文查找按回车／查询执行。
5. 原文件页码与解析文本阅读段用不同标签。阅读分段与AI分段配置分别表达，显示分段不得截短执行或导出正文。
6. 每份文件可保留当前访问期间的阅读位置。返回任务资料时保留查询、状态及分页。
7. 解析状态只描述资料准备；分析状态只描述某次工具任务。“分析成功”不代表审计结论已确认。
8. 无真实进度或时间估计依据时，不展示虚构的百分比或剩余时间。
9. 失去预览权限时不恢复阅读缓存内容；隐藏失权文件的名称和路径。所有操作继续校验当前权限。
10. 桌面正文及输入仍以16px为基准，辅助说明不低于14px；1024×480场景保留正文滚动和可达操作，不能通过缩小字体解决数据量问题。

实施及后端接入边界见：`../交互原型/大批量资料与长文档-交互设计与实施.md`。本补充单独交付，既有v1.3 PDF不包含本章。
