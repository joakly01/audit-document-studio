# 分析提示词选择与配套规则规范

更新日期：2026-10-23。适用于时间轴、主题归纳、会议纪要、风险点、合同、招投标、待摊费、工程一致性和两表分析的提示词选择、编辑、保存及历史回溯。与第15、23、24号中涉及“分析方案”“使用方案”“方案管理”或整套配置覆盖的内容冲突时，以本补充为准；资料选择、结果阅读、视觉和权限规则继续沿用既有规范。

本规范依据原前端实际选择逻辑，不扩大为新的方案产品。词云的用词设置与信息提取的字段模板保持各自业务定位。

## 1. 名称与页面层级

普通选择直接使用“选择提示词”，选择框提示“请选择提示词”或“搜索提示词”。按阶段标明“信息提取提示词”“主题归纳提示词”“会议风险提示词”等，内容区称“提示词内容”。不使用“分析方案”“使用方案”“应用方案”“方案管理”。

右栏仍先说明要完成的业务，例如“设置归纳要求”“设置会议分析”；提示词是该业务设置中的具体项。选项显示真实名称及必要的系统或个人来源，不把提示词库与提取字段模板混为一谈，不增加重复的整套选择框。

主要路径为“添加资料—选择或调整提示词—开始分析—查看结果”。核对原文为辅助操作，不要求逐份预览。选择提示词、应用编辑或另存均不直接开始分析。

## 2. 每阶段独立选择

| 工具 | 选择项 | 普通选词的影响 |
| --- | --- | --- |
| 时间轴 | 时间轴分析提示词 | 更新该提示词ID、名称和正文 |
| 主题归纳 | 信息提取提示词、主题归纳提示词 | 分别更新；保留先提取再归纳的流程 |
| 会议纪要 | 会议与议题提示词、会议风险提示词 | 分别更新；聚类参数与后续风险报告执行时机独立 |
| 合同 | 合规分析提示词、信息提取提示词 | 只更新各阶段；合同类型和检查规则独立 |
| 待摊费 | 提取计费约定提示词、费用计算提示词 | 只更新当前阶段；不改计费基数、既有约定及计算结果 |

纯文本阶段只替换当前ID、名称和正文，不带入其他阶段、字段、参数、资料、任务名称、附件或结果。双阶段工具不能把一个选择解释为同时配置全部阶段。

自动带入仅沿用原工具默认逻辑：优先恢复当前草稿；历史任务使用自身快照；库中默认提示词不覆盖已有编辑。待摊费按费用类型自动匹配时，保留原手动选择保护，选某条提示词不反向改变费用类型。

### 提示词来源与默认选择

提示词库分为“公共提示词、机构提示词、个人提示词”。公共提示词下保留“场景提示词、功能提示词、系统提示词”三类；工具内的内置默认项归属“公共提示词 / 系统提示词”，选项以“系统默认”标识。新建且尚未调整的工具配置按当前功能、当前阶段选中对应默认项；不能将系统默认和个人保存项混称为模板。

选择框按完整来源分组，仅提供当前工具、当前阶段适用且有使用权限的提示词。无适用项的分类显示“暂无适用提示词”，分类标题不能作为执行项。控件下显示当前来源路径，用户无需展开也能判断正在使用系统、机构还是个人内容。个人保存项在“个人提示词”组直接选择；无个人项时仍可从“编辑 → 另存个人提示词”保存后复用。

另存明确写入个人来源、工具及阶段功能类型，保留当前环节的配套规则。刷新恢复个人选择、修改后的正文和当前草稿；不能在每次进入页面时强制重置默认。历史记录的提示词后来被删除、停用或失去权限时，显示执行快照名称与正文，只读保留，不借用另一来源的同名提示词。

## 3. 带配套规则的提示词

以下内容来自原提示词配置，应完整保留。取消“方案”名称不能删掉这些能力，也不能把规则丢失的纯正文副本伪装成完整可执行提示词。

| 工具 | 配套内容 | 更新边界及说明 |
| --- | --- | --- |
| 风险点 | 风险点树及配置指定的勾选项 | 当前提示词正文与风险点清单；不改资料和检查方式。界面显示“选择风险点”，说明“选择提示词后，勾选本次要检查的风险点。” |
| 工程一致性 | 字段映射、权重、判定规则、阈值、补充提示词 | 重复项目和主子项目分别更新，另一模块保持；规则区域称“字段与判定规则” |
| 两表分析 | 字段匹配、权重、评分、硬规则、补充提示词、执行与匹配策略 | 替换当前两表对比配置，不改两份资料或任务信息；规则区域称“字段匹配与判定规则” |
| 招投标 | 当前分析模式的检查规则ID和规则元数据 | 招标、投标、联合分析分别选词与保存；规则区域称“检查规则”，不覆盖其他模式或项目文件 |

合同规则由合同类型加载，不属于合同提示词选择时自动覆盖的内容；不能因合同页面也有规则就把它误并入提示词。

切换会覆盖本次编辑时，确认窗口列出当前阶段的实际影响。例如“将替换本次重复项目的字段、权重、规则和补充提示词”，操作为“取消 / 确认切换”；不能笼统写成替换全部分析方案。取消恢复原选项、规则和草稿。

风险点清单更新后依原配置和有效ID恢复勾选，不保留失效ID；提示词没有配置风险点时显示空状态及处理提示，不静默回退到固定内置清单。工程、两表与招投标的规则来源和校验仍采用原工具契约。

## 4. 编辑与另存

- 提供“修改”或“编辑提示词”，正文编辑支持中文输入与长文本，输入过程中不重建输入框。系统原件与个人库原件不被本次编辑覆盖。
- 编辑形成草稿，“取消”保留应用前状态，“应用本次提示词”只更新当前阶段。“恢复默认”明确恢复当前阶段，不重置其他配置。
- 自定义正文与原库记录已不一致时按原契约标记自定义或清除原ID，不继续冒用未经修改的提示词身份；名称和历史快照仍可显示来源。
- “另存个人提示词”按当前阶段保存名称、正文、功能类型及原有配套规则，不保存资料、附件、任务名称备注、其他阶段或结果。保存副本与是否采用为两个明确动作，不能暗中替换当前选择。
- 配套规则编辑、重置、校验及原有必填仍保留。保存后的提示词可在对应工具、对应阶段选取，不能跨阶段错误复用。

## 5. 旧记录、历史快照与完整配置

旧个人记录可以继续显示和复用。若旧记录含整套配置，只抽取当前工具、当前阶段的提示词及其相关规则；不能把旧整套配置直接赋给当前工作区，不删除用户旧记录。阶段缺失时明确提示，不用另一阶段或系统默认静默补齐。

任务信息显示执行时的只读快照。提示词库后续改名、删除或修改均不改写历史记录；原提示词不可见时仍展示已保存的正文和名称。会议后续风险报告的提示词草稿单独保存，不回写已完成的会议议题快照。

完整配置JSON导入、导出仍可作为独立低频能力，名称为“导入配置”“导出配置”，与普通选词分开。导入前说明实际影响，保留工具、版本、字段和规则校验及确认；不能放入提示词选择项，也不能以“选提示词”为名整体覆盖。导出保留必要配置而不误含资料正文或结果。

## 6. 验收与接入边界

逐项检查：

1. 时间轴、主题、会议、合同、待摊费的普通选词只改变对应阶段ID和正文，其他阶段、参数及资料保持。
2. 风险、工程、两表、招投标携带规则可回读；覆盖仅限当前阶段，确认与取消均正确。
3. 另存只写当前阶段，保存后能重新选择；旧个人记录逐阶段兼容，不出现整套覆盖。
4. 历史任务只读，库记录更新或删除不影响执行快照；下一次报告草稿与原任务设置分离。
5. 编辑取消、中文输入、长文本滚动、低高度操作和正式参数校验完整；不依赖缩小字号适配。
6. 完整配置导入导出独立可达，保留原结构及校验，不混进普通提示词操作。

正式提示词库、权限、功能类型、规则配置、ID与正文请求字段沿用原接口。界面名称不构成新增后端协议；本规范不代表模型、真实提示词库或后台任务服务已经联调完成。
