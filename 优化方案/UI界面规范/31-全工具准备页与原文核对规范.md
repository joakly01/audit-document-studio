更新日期：2026-10-23。依用户最新要求，按原文对业务操作的实际作用决定布局；本规范优先于此前全部工具统一三栏的约定。

| 工具 | 准备页 | 原文的用途 |
| --- | --- | --- |

| 词云分析 | 分析资料 / 统计设置两栏 | 按需核对词语上下文，不承担分词规则的必填配置 |
| 主题归纳 | 待归纳资料 / 归纳要求两栏 | 核对资料内容；要点提取、主题归纳提示词分别配置 |
| 时间轴分析 | 事项资料 / 提取要求两栏 | 按需核对事项和日期，分析后仍保留时间线及来源 |
| 风险点分析 | 核查资料 / 检查内容两栏 | 选择风险点和遍历方式后执行，核验线索时再打开来源 |
| 会议纪要分析 | 会议资料 / 会议分析设置两栏 | 原文按需；结果中的会议时间轴、议题聚类、详情、筛选、风险及问答均保留 |

| 两表项目关联度 | 两张台账 / 对应字段与比较规则两栏 | 清楚展示两侧映射与结果源行，原始台账按需 |

## 共用操作

1. 左侧显示本次已选资料，添加入口与清单标题同一行。文件名可打开原文件与解析内容；关闭预览后资料选择、配置和滚动位置保持。
2. 两栏工具的步骤为“Step 1 资料 / Step 2 设置”，信息提取沿用三个步骤。主要执行操作固定在右上，按工具使用开始统计、开始归纳、开始核查等业务动词。
3. 预览不参与是否可提交的判定；仍按解析状态、权限、资料类型、映射及规则校验。不能要求用户先浏览原文才能执行。
4. 两栏准备页不构建或挂载已移除的原文区域；长资料按需打开，减少操作时的无效渲染。原件、解析正文和下载权限沿用原检查。
5. 窄屏仅切换已选资料与分析设置；原文从文件名进入弹窗，不保留空的原文页签。表格与设置区各自滚动，主操作与页脚可达。
6. 完成后进入工具本身的结果页；不得把会议时间轴、词云、项目对比等业务成果当作“中间预览区”删除。
7. 任务中心查看结果、任务信息、导出数据三项操作保持。任务信息只读；调整后再分析复制实际执行的资料及设置，原任务保留。

## 前端与接口边界

本轮采用准备页布局和原文入口调整，资料选择、提示词、参数、执行、阶段续算与结果接口沿原功能承接。没有为两栏布局增加后台接口；工具请求快照按原前端结构核对，正式服务仍按原接口联调。

核对原 `OcrViewer.vue` 与词云提交构造函数、`ThemeAnalysisViewer.vue`、`TimelineAnalysisViewer.vue`、会议分析 `index.vue` 及风险点原型。词云预览可隐藏，时间轴原本即支持弹窗原文，主题和会议提交依赖资料与配置而非常驻预览。信息提取的字段核对场景单独保留。

## 验证

`tests/browser_tool_preparation.py` 覆盖五个共用工具的两栏、原文双栏往返、请求与配置不变、不预先渲染正文、提交与结果，包含1366×768、1024×480、390×600。三项专用工具另有独立业务回归；信息提取三栏和11工具历史复用由共用检查覆盖。
