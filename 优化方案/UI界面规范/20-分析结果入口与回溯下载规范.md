# 任务中心与分析结果操作规范

更新日期：2026-10-22，以本版三项操作名称和样式为准。

## 定位与布局

任务中心的“分析结果”汇集各 AI 工具的审计分析成果；“运行监控”查看执行阶段、排队和异常。每种工具保留自身业务结果，不使用一种通用报告取代所有工具成果。

列表优先展示分析名称、工具、状态、成果摘要及操作。提交时间放在名称下方。表格内部滚动，保留字号和分页，不通过缩小字体容纳全部内容。

## 三个操作

| 固定名称 | 用途 |
| --- | --- |
| 查看结果 | 进入本工具结果页面，核对内容、线索及原文依据 |
| 任务信息 | 查看任务状态、资料范围、失败原因、执行时的配置 |
| 导出数据 | 选择需要导出的成果、范围与格式 |

操作栏仅保留以上三项，顺序固定，均为纯文字，无前置图标，不再追加更多菜单。字号16px，点击高度36px，蓝色文字与明确的禁用态。任务尚无结果时禁用查看和导出，任务信息可用。合并导出任务使用同一组三项文字，查看其来源和生成文件。

记录备注、删除和终止等低频管理操作放在任务信息中，运行中的终止仍可使用。完整配置通过任务信息的执行配置页签进入；历史配置只读，查看历史不得覆盖新任务草稿。保留既有历史配置和导出页面链接。

## 结果页面

查看结果后不展示左侧资料清单，释放空间给表格、图表或报告。保留来源文件与原文核对入口；资料范围在任务信息中查看。新建分析仍保留资料选择区。

2026-10-23补充：信息提取、词云分析及主题归纳结果页的顶部仅保留“导出”。任务信息和配置回溯仍从任务中心进入；结果页不重复放置复制新建、本次配置等按钮。细则见第23号补充。

## 导出数据

按工具提供明确的成果名称，如提取信息表、词频明细、会议议题清单、风险线索清单、项目关系候选。图片、报告、问答、表格分项说明。未生成的成果禁用并提示原因。

导出前明确范围和格式；保留来源与执行配置。部分完成只导出已返回结果；入口及导出确认时复核权限。

## 审计业务与演示状态

提取值可核对原文；风险是待核验线索；关联关系和重复项目为候选。不得将AI分析完成等同于审计结论确认。

演示任务明确标识。排队与执行演示快照注明不实际执行，刷新不重复添加，不覆盖已有任务和草稿。
