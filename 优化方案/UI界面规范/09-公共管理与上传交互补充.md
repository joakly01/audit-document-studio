# 公共管理、工具箱与上传交互补充

> 2026-10-19：有效规则已合并至v1.3主规范。本页保留历史追溯；与主规范有差异时，以用户最新要求和v1.3主规范为准。

2026-10-18，补充 v1.2，以本页和最新用户要求为准；历史 PDF 保留对应版本，未合并本轮增量。

- 工具箱常态宽260px，1280px及以下240px，1050px及以下210px；移动端按需展开。表格底栏选中统计数字18px，正文16px、辅助14px；不通过缩小字号腾空间。
- 已选提示移至中间表格底栏，显示已选文件、解析完成和解析未完成；详细解析状态在提示和清单中查看，权限变化单列。资料范围、工具适用性和实际解析完成分别表达。
- 取消“未关联原文”独立状态；实际缺少文件时，在尝试操作后的反馈中说明原因。不能因此标记为完成或允许绕过核验。
- 更多菜单按检索与记录、窄屏筛选、所选资料、目录与界面分组。文本检索第一项；取消文件列表排序，左侧目录同级拖动排序保留。菜单中入口不重复，危险操作有确认。
- 公共空间按原权限保留新建、重命名、权限管理、绑定项目、绑定机构、删除。项目与机构分别编辑，不互相覆盖；绑定状态使用链接和机构两种不同图标。系统内置和机构根目录限制继续生效。
- 上传窗口提供明确位置、一块完整拖放区、文件/文件夹并列选择，选择后显示本次清单。常态不展示空进度和多余提交按钮；本次进度与全部上传记录区分。
- 多文件、100MB、完整层级、空目录、筛选、合并、重名、子目录权限和错误重试属于核心能力，不能因视觉简化删减。
- 上传弹窗常态宽740px、屏幕四边保留间距，窗口内部滚动；1024×480和390px宽度下仍能操作。图标继续使用统一注册表：file、folder、upload、uploadHistory、link、building、accessKey，不另画雷同图标。
