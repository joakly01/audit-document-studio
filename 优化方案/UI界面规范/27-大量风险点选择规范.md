# 大量风险点选择规范

更新日期：2026-10-23。补充第24、25号规范中的风险点准备、选择与只读回溯，不改变检查执行和结果判断逻辑。

## 页面与操作分工

配置栏依次显示风险分析提示词、检查风险点概况和检查方式。风险点概况只显示已选数量、清单总数及有限的分类汇总，不将完整清单堆在窄栏中。点击“选择风险点”进入集中选择窗口。

选择窗口提供业务分类、关键词搜索、“全部风险点 / 已选风险点”切换、列表及分页。风险点名称和检查说明供浏览，完整编辑放入单项表单，保留新增、编辑、删除及校验功能；不为清单中的每个风险点创建编辑表单。

桌面使用可展开的分类树，显示分类“已选 / 总数”及半选状态。小屏改用分类下拉框，给风险点清单留出更多空间。列表、分类各自滚动，底部已选数量与确认按钮固定可见。

## 选择范围

- 勾选分类：包含该分类的全部下级风险点，与右侧检索条件无关。
- 勾选“本页”：只改变当前页的风险点。
- “选择全部页（数量）”：只选择当前分类、关键词和列表范围匹配的全部页。
- “取消当前范围选择”：只取消当前匹配项；其他分类和不匹配的已选项保留。
- 切换分类、翻页或搜索不清空选择。“已选风险点”集中核对本次勾选；取消勾选只改变本次选择，不删除风险点。
- 中文输入法预编辑期间不重建输入框；勾选保持当前列表滚动位置。

## 草稿与执行边界

进入选择窗口建立独立草稿，新增、编辑、删除与勾选均先作用于草稿。点击“确认选择”后应用到本次配置；关闭未确认的修改时可继续编辑或放弃，原配置保持不变。风险点名称、业务分类、检查说明必填，名称继续沿用原有唯一性校验，应用前至少选择一个风险点。

风险点来源仍由提示词配套配置驱动，不引入独立的风险点方案或另建业务库；提示词未配置风险点时保持空态，新增检查项由用户明确操作。修改本次风险点不回写提示词库。

提交继续使用原执行契约：`risk_points` 保留每个叶节点的 `id / path / label`，检查方式保持 `byRisk / byFile` 的原映射，不把业务分类当成需要执行的风险点。

任务信息中默认展示“已选风险点”，可按分类和关键词查看；风险点详情只读，没有勾选、保存或删除操作，历史执行快照保持不变。风险结果的线索状态、分组、来源、筛选和导出沿用既有流程。

以1000个风险点检查分类含下级选择、本页与全部页范围、检索取消、半选计数、已选核对和编辑草稿。检查1366、1024×480及390屏宽，清单分页、中文输入、滚动位置、底部操作及只读历史。大量清单不在侧栏或选择窗口中一次挂载全部编辑控件。
