# 嵌入布局与文件预览补充

> 2026-10-19：有效规则已合并至v1.3主规范。本页保留历史追溯；与主规范有差异时，以用户最新要求和v1.3主规范为准。

2026-10-18。增量规范优先于历史PDF对应内容。

1. 外部框架负责全局页头。本工具不再重复展示顶部面包屑、账户和帮助栏；各工具自身名称、执行入口及资料当前位置保留。资料区使用完整可用高度。
2. 资料操作单行“当前位置、名称搜索、筛选、上传、更多”；按可用宽度收纳筛选，不缩小文字或挤压路径。资料操作栏和更多不设任务中心，统一从左侧导航进入；当前位置不显示锁图标，权限约束保留。
3. 文件夹筛选表包含文件名称和相对路径；前三项直显，完整清单可搜索翻页，返回不丢勾选。同名不同目录必须可区分。
4. 文件预览同时两栏：左原始文件、右解析内容，各自滚动；明确区分文件解析状态与分析任务。不得拿解析文本拼装为用户上传原件。未解析、失败、原件缺失分别处理。
5. 下载原件与导出解析内容区分。解析内容导出统一下拉菜单，提供Excel、Word、Markdown；无解析内容或权限不足时不可用。源文件外部资源不默认执行或联网。
6. 表头全选标注“本页”，只处理当前页文件。选中后在列表底部提供“选择全部页（N份）”，明确其受当前目录和筛选约束。仅保留本页/取消本范围不误清其他范围已选；清空已选为全局动作。全选具备半选状态，文件夹不参与。
7. 所有新增文字遵循正文16px、辅助14px；低矮窗口保留表格、独立滚动及可见的分页与弹窗底部操作。
