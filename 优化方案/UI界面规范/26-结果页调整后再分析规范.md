# 结果页“调整后再分析”规范

更新日期：2026-10-23。适用于全部11项工具从历史结果返回可编辑准备界面、调整后提交的流程。共用视觉、资料权限、提示词选择及配套规则继续沿用既有规范；此前结果页“仅保留导出”的约定补充为保留必要的“调整后再分析”和“导出”，不恢复复制新建、本次配置等重复入口。

## 1. 业务目的与入口

“调整后再分析”用于发现资料、提示词或检查参数需要修改时，沿用当前记录的实际输入进入准备界面。点击后只创建可编辑草稿，不运行任务、不新建分析记录、不改写原结果。用户完成调整，点击工具原有开始按钮并确认提交后，才生成新的分析记录。

结果页入口保持直接、简短，与“导出”并列。任务中心操作仍为“查看结果 / 任务信息 / 导出数据”三个纯文字动作，不增加第四项。任务信息继续用于只读回溯，不成为编辑历史任务的入口。

## 2. 继承内容与隔离边界

新草稿继承当前记录的资料范围、实际执行配置和各工具必要的业务输入；提示词及原有配套规则按阶段保留，不只复用展示名称。新任务保留来源记录的追溯关系，原任务的状态、时间、进度、结果及执行快照不变。

| 工具或输入 | 继承与处理 |
| --- | --- |
| 全部工具 | 已选资料、各阶段提示词和本次参数；进入后重新检查当前权限、解析状态及工具类型限制，不静默丢弃不可用资料 |
| 信息提取、合同及可关联附件工具 | 继承执行时的主文件—附件关系，建立独立附件草稿；新增或移除只作用于本次草稿，不改资料库关联或原任务快照 |
| 词云 | 继承实际执行的停用词和用户新词快照，并纳入明确标记为下次生效的停用词；不因当前词库变化静默丢弃旧任务用词 |
| 会议纪要 | 保留会议议题与风险分析两个阶段；后续风险报告采用过或已应用的要求按明确优先级带入，不复制风险报告、问答内容或生成状态 |
| 主题归纳、时间轴 | 保留对应阶段提示词及原执行参数，旧归纳报告与事项结果不作为新任务结果 |
| 风险、工程、两表、招投标 | 保留原风险点、字段映射、权重、规则、阈值、模式、项目单位与资料角色；按第25号规范维持阶段及模块边界 |
| 待摊费 | 保留费用类型与两阶段提示词；旧计费基数仅可用于下一阶段预填，仍需核对新提取约定并点击计算，不复用旧费用作为新结果 |

新草稿的原文预览应指向当前已选范围中的有效资料，不显示其他未提交草稿的无关文件。招投标待指定角色清单由复制后的范围与项目角色重新确定，不残留另一份草稿的未分配资料。

## 3. 草稿、历史与运行状态

- 从准备界面查看历史结果再返回时，保留准备中的资料、字段、提示词、规则和独立附件草稿；浏览历史不改变未提交内容。
- 点击“调整后再分析”后，界面明确处于可编辑准备状态。新草稿可继续添加或移除资料、修改提示词和参数；取消提交不增加记录。
- 已运行记录只读。草稿修改、库记录更新、资料库附件关联变化和新任务完成，均不得回写原任务。
- 运行中继续采用“停止”操作，不能把“调整后再分析”冒充暂停或中途改配置。部分失败的“重试失败文件”沿用原任务及成功结果；完整调整后重新分析是另一条链路，不能混淆。
- 报告重新生成、只重试主题归纳阶段、待摊费后续计算等已有阶段操作保持原业务语义，不被统一入口替代。

## 4. 验收与接入

检查点击前后任务记录数量不变，准备页可编辑且配置完整；只有确认提交才增加新记录，并能回溯来源。逐项核对原任务的完整序列化快照未改变、普通历史访问可恢复准备草稿、权限变化仍被原校验拦截。

附件需验证历史关系与资料库当前关系不同时的展示、移除、撤销、新增、历史回访和新提交快照，确保两个任务和资料库各自独立。词云、会议风险要求、双表、招投标与待摊费需验证其实际执行输入，不只检查通用配置对象。

正式后端接入继续沿用各工具创建新任务的原接口，来源关联由实际支持的契约实现；不得以本地前端追溯字段推定服务端已支持。浏览器交互检查与正式模型、队列及鉴权联调分别记录。
