# 通用分析工具补充

> 2026-10-19：有效规则已合并至v1.3主规范。本页保留历史追溯；与主规范有差异时，以用户最新要求和v1.3主规范为准。

适用于词云、会议纪要、风险点、时间轴与主题归纳；沿用资料管理、提取模板和信息提取的整体视觉与交互规格。与历史图示冲突时以本补充为准。

## 1. 工作区与密度

- 无独立全局面包屑/说明卡，业务操作栏常态56px、低矮桌面50px，主操作保持单行。
- 左为本次资料，中为资料清单/结果，右为本次配置。左资料固定保留“添加资料”；结果默认收起右配置，按需“本次配置”展开。
- 左目录按公共、项目、个人空间组织，同层文件与目录共存。点击文件预览、点击目录过滤视野，均不改变执行范围。
- 搜索、结果视图切换和查看详情不触发重新执行；“复制新建”保留历史任务。历史及停止任务的配置只读。
- 核心内容独立滚动，宽表横向滚动，关键来源操作固定右侧。低分辨率通过收纳和滚动适配，不缩小字号。
- 正文/输入/主操作16px，工具标题18px，弹窗标题20px，辅助说明/表头/行内链接不低于14px；数值采用统一数字宽度并以主题色强调。
- 弹窗不超过可视高度减28px，编辑区可伸缩或独立滚动，底部取消/应用保持可见。检查1024×480嵌入窗口，不能仅检查桌面全屏。

## 2. 操作层级

| 阶段 | 主要操作 | 辅助操作 |
| --- | --- | --- |
| 准备 | 开始分析 | 左侧添加/管理资料，右侧编辑配置、另存方案与更多 |
| 提交 | 确认分析 | 名称、备注、提交后去向；词云保留调整本次选词 |
| 执行 | 停止分析 | 任务中心、逐文件处理状态 |
| 完成 | 导出 | 本次配置、复制新建、任务中心；结果内部保留搜索/筛选/来源 |
| 次级分析 | 生成风险报告 / 重试归纳 | 使用已取得的常规分析或基础信息，不能冒充重新处理所有源文件 |

“更多”收纳导入分析方案、导出配置、查看完整配置等低频功能，不重复已经直接展示的按钮。分析方案与提示词模板分开：前者保存全部参数，后者仅替换对应阶段的分析要求。信息提取的字段模板仍单独管理。

## 3. 五种结果呈现

- 词云：词云/词频/组合视图，词频数字突出，点击词语核对来源；次数不表示风险。停用操作标明下次生效。
- 会议：常规分析/风险分析/深度问答三主入口，常规分析内再分议题归类/会议时间轴/议题清单；七部分报告提供章节导航。
- 风险：默认聚焦匹配线索，按风险点/文件归组；需核验、未匹配、资料不足分开。风险等级仅展示原结果提供的数据。
- 时间轴：按日期组织，未知日期独立展示；章节/事项展开与原文查看分开，日期来源不能写成上传日期。
- 主题：主题阅读与基础信息表切换；两个阶段配置独立，失败阶段可重试并保留成功结果。

## 4. 核验、导出与词库

结果与原件双栏核验，右侧可切换解析正文；词语/证据仅在正文真实存在时高亮，没有精确页码/坐标时不得伪造定位。导出明确全部/当前筛选/指定文件范围，保留来源与执行时配置；问答与风险报告采用对应独立格式。权限变化后不能继续显示或下载不可访问的来源内容。

词库导入采用“读取 → 冲突预检 → 逐行/批量处理 → 加入清单 → 保存词库”；覆盖另一类型时移出旧类型，不允许两类同时存在同词。重复词、空值、超长词、取消/放弃、分页与搜索均应可测试。

## 5. 图标

- 工具沿用 cloud（词云）、message（会议）、shield（风险）、timeline（时间轴）、layers（主题）。
- 清单/词频使用新登记的 list 图形，避免退化为文件图标。任务中心用 tasks，配置用 settings，日期筛选用 filter，执行用 play，停止用 pause，导出用 download。
- 更多仍为三个实心点；同一含义跨工具一致，图标按钮有可访问名称。参见图标注册表和新增 list.svg。

完整原功能核对及服务映射见工程《通用分析工具-原功能核对与接入说明》。本补充规定界面行为，不代表独立前端已接入正式算法或权限服务。


## 其他十项工具与信息提取对齐（2026-10-19）

准备页面统一为三栏，左右等宽：Step 1 添加资料、Step 2 核对原文、Step 3 使用业务含义明确的配置名称。正文及输入16px、辅助说明不低于14px，操作栏不超过56px；1024×480保留三栏，窄屏按步骤切换。添加入口与左栏标题合并，不重复放置中间资料表格；左侧文件单行显示，关联附件与移出采用含义明确的图标。查找和预览均不改变执行范围，移出只取消本次选择，并提供撤销。

资料选择区分“本页”与“全部页”，后者遵循当前目录、是否含子目录及检索条件。仅解析完成、类型受支持且具有分析权限的资料可选，提交时再次校验；表槽维持各自单选。原件和解析文本可切换、可展开双栏核对，编辑右侧配置时保持当前原件页码和滚动位置。

各工具保留独立业务逻辑：词云的本次词表及个人词库；会议的常规分析、风险报告和问答；风险点的层级、勾选与遍历顺序；主题的两阶段要求及失败阶段重试；时间轴的事项日期与未知日期分组；合同的类别、规则、自动分析及附件合并；待摊费用的约定提取、基数输入与费用计算；工程项目的重复/主子项目独立字段和评分配置；招投标的项目、单位、文件角色及三种分析内容；两表关联的双表业务名称、字段映射、硬规则、评分、四项锁定和比较上限。不得为了统一布局而合并这些业务步骤或改写请求参数。

其他工具的“分析方案”保存自身业务参数，与信息提取的字段模板分开。删除通往提取模板管理的错误链接；阶段提示词仍独立编辑，另存个人方案、配置导出和完整配置查看继续可达。

默认工具地址进入可编辑准备页；回看结果使用明确任务地址。历史资料、配置与结果只读保留，停止任务也不得直接修改快照。返回普通工具入口恢复未提交配置；复制新建后再修改。项目归组和双表选择同样作为独立草稿保留。
