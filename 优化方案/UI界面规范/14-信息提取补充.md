# 信息提取界面补充

> 2026-10-19：有效规则已合并至v1.3主规范。本页保留历史追溯；与主规范有差异时，以用户最新要求和v1.3主规范为准。

2026-10-18。本补充优先于旧信息提取线框中的布局描述，与资料管理和提取模板共用色彩、字号、表格、按钮及弹窗规范。

## 页面结构

- 保留一行业务操作栏，不恢复系统级标题、面包屑或大面积说明。常态56px，低矮窗口48px。
- 左右两侧均368px；中间弹性。宽度不足1200px时两侧均320px。所有栏目各自滚动；窄工作区的位置字段并入文件名下方，标明“位置”，与操作列互不遮挡。
- 准备阶段中间默认原始文件，可切换解析内容，与右侧字段编辑同屏；结果阶段默认隐藏右配置，按需“本次配置”展开。
- 不另设任务配置说明卡、大数字概览或重复执行入口。执行前的名称、备注、执行方式合并在同一弹窗。

## 操作与图标

| 操作 | 表达与位置 | 图标 |
| --- | --- | --- |
| 添加资料 | 左侧固定按钮，执行后仍可添加到新任务 | plus |
| 开始提取 | 准备阶段右上主按钮 | play |
| 停止提取 | 执行中右上，确认后终止 | pause |
| 本次配置 | 完成后右上，打开只读快照 | settings（滑杆） |
| 复制新建 | 完成后右上 | copy |
| 导出结果 | 结果右上主按钮；配置导出在独立提取模板管理中 | download |
| 关联附件 | 每份文件旁直接关联；窗口明确附件是否参与本次全部资料提取 | paperclip，使用现有实心/线性一致图标资产 |
| 模板 | 下拉选择与另存个人模板；管理从系统菜单进入 | book |
| 展开/收起目录 | 目录名称前；不承担移除操作 | chevron/down |

主按钮与正文16px；辅助说明、表头、位置、次要行内操作14px。字段值18px仅用于核验详情重点。不把细文件类型缩写作为操作按钮。

## 规则、状态与选择

- 明示“本次全部资料共用以下提取规则”。修改字段与取值口径作用于本次配置副本，不覆盖模板。
- 字段名称必填且唯一，字段说明可选；右侧直接输入名称和说明；增删及行尾更多中的顺序调整作用于本次字段，不改原模板。字段列表即本次提取字段范围，不另设勾选。
- 本次字段即时保存；独立模板编辑仍保留保存/取消和未保存修改确认。900px以内使用资料/原文/字段面板切换。
- 准备资料显示“解析完成/解析中”等；任务结果显示“提取完成/提取失败”等。绝不使用含义不清的“完成几个、待处理几个”。
- 提取状态仅用“已提取”“未提取到”。不能把模型取到值标成“准确”，不能补造置信度。
- 结果数、失败数、字段数突出数字，单位与文字采用普通字重。
- 表头标“本页”，提示选择范围；跨页已选保留。选满本页可继续选择当前筛选的全部结果。导出时明确全部/所选/指定文件。
- 结果搜索和目录查找只过滤展示，不改变任务资料快照，也不重新提取。

## 原件核验

- 左原始文件，右提取结果；右侧可切换解析内容。
- 每字段按名称、取值、提取口径、原文证据排列；缺失时明确原因与核对方向。
- 原件保留真实PDF页码与缩放、Word/表格预览及原文件下载；支持前后文件切换。
- 精确高亮已有解析证据；不能取得原件坐标时不声称已定位PDF页内位置。
- 导出保留证据来源。Excel三个工作表分别承担汇总、逐字段证据与任务配置，避免把依据挤进主汇总表。

## 验收

检查1440×900、1366×768、1024×480和窄屏；嵌入框架后以iframe实际高度计算。低分辨率保持字号，通过独立横/纵滚动和收起配置保留核心空间，不叠加第二行主操作。

覆盖空资料、模板替换取消、字段重名/空字段、参数越界、执行中、全部成功、部分失败、失败重试、停止、缺失字段、历史快照、下载权限变化、跨页选择和真实导出文件。

实现与源功能映射见原型工程 `信息提取-原功能核对与接入说明.md`；证据见 `review/extract-workflow-checks.json` 与配套截图。

## 新人操作指引（2026-10-19更新）

三栏标题为“Step 1 添加资料—Step 2 核对原文—Step 3 配置提取字段”，Step 1标题与添加按钮共用一行。信息提取不再提供批量移除，仅保留逐份移除及撤销。文件名占满可用行宽，解析状态和关联附件/移除置于下一行；点击关联附件不改变当前预览与主文件范围。原文预览标题40px，文件名一行，PDF页码、翻页和缩放保持单行，路径悬停可查看，不缩小正文。添加资料弹窗移除“加入目录”重复入口，仍支持本级/子文件夹、本页/全部页、文件夹选择和上传。

## 附件选择与解析就绪（2026-10-19）

附件关联对照原 `AttachmentSelectDialog.vue`：候选为已添加资料加已打开目录文件，排除主文件与已有附件；支持中文检索、本页/全部页勾选、确认追加、取消返回、不改主文件范围。关系独立于目录重命名/删除能力；显式附件禁权、有权读取但无提取能力及历史快照不可修改。选择主文件时展示各解析状态，仅解析完成且有提取权限可选；全选、切页和提交复核一致。

## 大量文件的紧凑清单（2026-10-19）

附件与移除只用纸夹、关闭图标，提供悬停说明和可访问名称；已有附件浅蓝底标识。准备清单不重复显示解析完成，文件名单行截断并可查看全名，约42px行高。异常和提取执行状态保留。右侧删除管理链接，另存个人模板仍直接可用。选择提示为“可跨目录选择，仅添加解析完成的资料”；原文预览、关联附件均按需操作，不作为必做步骤。

### 2026-10-19 模板默认及按钮分工

新配置默认不选模板、不预填字段；可明确选模板，也可自行添加字段。保留已改草稿和历史快照，只迁移旧版完全未改动的自动预设。“另存为个人模板”移至模板选择区次要操作；字段栏的“添加字段”采用标准描边加号按钮。空字段时禁用保存/开始并说明下一步，正常未开始状态不展示红色报错。
