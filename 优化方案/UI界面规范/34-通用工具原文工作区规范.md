# 通用工具原文工作区规范

更新日期：2026-10-24。本规范是31号、33号中“其他工具准备页默认两栏”条款的最新修订；资料选择、执行、权限、历史及各工具业务成果继续沿用原规范。

## 适用范围

词云分析、主题归纳、时间轴分析、风险点分析、会议纪要分析、待摊费用六项工具，准备页默认采用“资料—原文—设置”三栏。信息提取保持已有三栏。合同、招投标、工程项目一致性、两表项目关联度配置较重，继续两栏，原文按需查看。

三栏统一的是操作位置，不要求用户先逐份阅读再执行。Step 1添加本次资料，Step 2按需查看原文，Step 3配置本次分析内容；查看原文不设完成状态或提交门槛。当前预览文件只影响阅读，不改变本次参与分析的资料范围。

## 默认布局与操作

资料栏和设置栏默认各320px，中间原文使用剩余空间；实际宽度受当前工作区约束。分隔条支持拖动、键盘左右方向键微调，Home或双击恢复默认；宽度偏好本地保存，不进入分析配置和任务参数。正文及控件不依靠缩小字号容纳三栏。

左侧保留添加资料、目录检索、文件切换、附件关联、移除和已选份数。点击文件直接在中栏显示，不再为普通切换反复打开弹窗。中栏顶部只保留紧凑标题、文件名称、原文件/解析文本切换及放大查看操作；原文缩放和翻页继续使用既有预览器。

原文区域常驻，不提供收起／展开操作；旧的收起状态在渲染时恢复。步骤标题、文件名及原文件／解析文本切换合并为一行，PDF翻页与缩放使用紧凑工具栏。配置操作保留当前文件、已有原文预览会话与解析文本滚动位置。解析文本按需生成，并保留同一文件的DOM；PDF处于适合宽度模式时随面板宽度重新绘制。

右侧按工具保留原有设置，提示词卡片纵向排列，不把窄栏中的两个阶段挤成并排卡片。风险点仍通过已有分类检索弹窗管理大量检查点；待摊费用继续先提取计费约定、后填基数计算，不把准备态预览当作已经生成的结果。

## 按工作区宽度适配

| 实际工作区宽度 | 展示方式 |
| --- | --- |
| 不小于1000px | 资料、原文、设置三栏；允许调宽，原文常驻 |
| 620–999px | 左侧资料保持可见，右侧在“查看原文/分析设置”间切换 |
| 小于620px | “已选资料/查看原文/分析设置”三个面板切换 |

断点以嵌入框架后实际容器宽度为准，不以浏览器总宽度推断。窄屏不横向挤压三个面板；文件和配置状态在切换中保持。

## 来源与实现边界

预览继续检查文件及完整引用链的阅读、预览权限；没有原文预览权时显示明确占位，不能借解析文本绕过限制。可分析权限与原文预览权限分别沿现有规则处理，不因预览不可用而改写分析配置。页码、坐标和源文内容仅使用真实返回。

原Vue的会议和时间轴中间区域主要承接分析成果，并非全部都是准备态原文预览。本轮加入准备态中栏是为了统一通用工具的阅读和设置操作，不能描述为原界面逐像素还原。会议时间轴、议题聚类及时间轴事件结果继续保留，不用原文面板替代。

本轮只调整前端工作区及预览生命周期，复用原文件预览器、资料选择器、提示词配置和逐工具执行函数；不增加后端接口，不修改任务配置、附件快照或结果结构。结果页、任务中心及连续核验沿32号、33号规范。

## 官方参考与本轮判断

- UiPath的紧凑验证界面将原文和字段并列，可拖动分隔条，并随空间变化调整字段展示。这支持阅读区与配置区保持联系及可调整宽度的设计。[Compact Validation Station](https://docs.uipath.com/activities/other/latest/document-understanding/compact-validation-station)
- ABBYY的人工复核界面将缩略图、原文、字段及规则问题分为独立面板，允许隐藏或折叠。我们借鉴面板可收纳的处理，不增加强制人工复核流程。[Integrating manual review](https://help.abbyy.com/en-us/vantage/1/developer/developer_integrate_manual_review/)
- DataSnipper的Focus Mode将单条回答及其原文并列，允许连续切换并返回主表。我们继续区分准备页常驻阅读与结果页专注核验。[DocuMine Focus Mode](https://knowledge.datasnipper.com/en/articles/714302-how-to-efficiently-review-answers-using-focus-mode)
- Ant Design的Splitter提供多面板尺寸约束、折叠和双击恢复等交互范式；当前原型沿现有技术实现同类行为，没有引入整套组件库。[Splitter](https://ant.design/components/splitter/)

六项工具默认三栏、320px基准及容器断点是结合本项目配置复杂度和嵌入场景作出的设计判断，不代表参考产品要求所有工具使用固定三栏。

## 验收要求

检查六工具准备页、三栏/双面板/单面板切换、拖动与键盘操作、收起后的恢复、解析文本滚动、PDF适宽、失权占位及大量资料切换。另回归提示词与词库、附件、风险点、费用两阶段、提交摘要、结果与历史配置，确认只改布局、不改执行范围。本轮浏览器验收结果以应用工程相应测试和review报告为准；本文件不将旧测试结果视作新布局已通过。
