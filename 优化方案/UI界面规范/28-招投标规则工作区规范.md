# 招投标规则工作区规范

更新日期：2026-10-23。适用于招投标分析准备页、规则查看及历史执行配置；与此前所有工具统一三栏的约定冲突时，本专题按此执行。

1. 主要工作区采用“项目资料 + 分析内容与规则”两栏；原文通过文件名按需打开，保留原件与解析内容同时查看。
2. 项目资料直接配置项目、招标文件及多个投标单位。招标单选替换，投标按单位多选；移除仅解除本次关联，保留原文件。空项目可暂存，有文件但不符合模式要求的项目需补齐后执行。
3. 模式卡片内勾选决定执行范围，“查看规则”决定正在浏览的配置；不重复提供另一组模式页签。三个模式分别使用提示词、配套规则，切换浏览不改变执行范围；不能取消最后一种模式。
4. 配套规则清单以表格为主，名称、检查重点和查看说明清楚可见；大量规则支持检索与分页。规则清单完整随提示词执行，不添加与原系统不一致的逐规则勾选。
5. 提示词选择和编辑保持紧凑，默认公共 / 系统提示词，可切换个人副本。覆盖配套规则仍需确认；编辑正文不删除规则编号。完整配置导入导出收在次级“设置”入口。
6. 检索、分页、切换项目只影响呈现；确认提交保留实际项目、单位、模式、提示词及全部规则ID，不能只提交当前显示页。
7. 小屏仅在两栏间切换，长规则说明在详情中完整阅读；规则区独立滚动，分页和主操作可见，不缩小正文解决布局问题。
8. 历史任务的资料与规则只读，来源权限变化沿用原检查；“调整后再分析”生成可编辑草稿，原记录不变。
9. 结果区采用检查结果、分析资料、分析报告三个入口。按项目、环节、状态及风险等级筛选；详情保留判断依据、合理说明和建议，证据保留全部实际来源文件。
10. 结果缺失字段如实标注；无返回风险等级时不补造。联合证据中任一必要来源不可读或不属于本次任务，不展示或导出该条；撤销移除必须完整恢复资料归组与文件角色。
