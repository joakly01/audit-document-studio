# 完整业务流程与连续核验规范

更新日期：2026-10-24。承接32号规范与合合信息、DataSnipper操作模式调研，覆盖全部11项工具。日常流程为“选择本次资料 → 确认分析内容并执行 → 查看成果、核验依据、导出”。

## 资料与配置

资料管理负责归集、权限和解析；各工具只维护本次范围。模板、提示词和检查规则可复用，日常分析不要求重新维护公共配置，不增加重复的业务空间或问题库导航。信息提取模板默认不选。

添加资料仍使用同一个资料选择弹窗，支持当前页、全部页、跨目录与空间。弹窗中的“从分析记录选资料”允许选取原分析的主文件；它只更新选择暂存，最终确认才更新准备页，取消返回原选择。原分析的设置与历史附件快照不复制，精确复用原执行设置继续使用“调整后再分析”。

资料库带入已有准备草稿时，先确认资料处理方式，默认加入现有资料并去重；替换必须明确选择。配置保留，招投标已有项目和角色保留，新增资料进入待分配区。两表比较必须明确表一、表二，不按选择顺序自动取前两份。

引用文件与原文件均校验当前阅读、分析权限、解析状态和文件类型；来源不可用时不带入。历史任务与待编辑草稿保持独立，浏览记录不改写历史。

## 准备、提交与运行

信息提取保留资料、原文、字段三栏；其他工具保留资料与设置两栏，原文按需查看。两栏工具统一Step 1资料、Step 2设置，已有业务名称保留。

提交前使用紧凑摘要说明实际参与的文件、字段/检查内容及预期成果。展开后才查看完整资料路径、字段描述、所选规则、项目角色或两表映射。摘要读取本次实际配置，不用默认示例代替用户选择，不改变原控件、校验和执行参数。

开始后在当前工具查看进度及结果，分析记录负责找回。运行页可解释本工具处理链路，但未取得后端阶段状态时，只标明“本次处理内容”，不得虚构分阶段完成勾选、预计等待时间或排队位置。

## 各工具的业务衔接

| 工具 | 本次确认内容 | 完成后承接的成果与后续操作 |
| --- | --- | --- |
| 信息提取 | 主文件、附件开关、实际字段及口径 | 字段汇总、原文/字段双栏、按需核验与导出 |
| 词云分析 | 资料、词数上限、停用词与用户新词 | 词云、词频表、词语来源 |
| 主题归纳 | 要点提取与主题归纳两类要求 | 基础信息、共同主题；阶段失败沿原机制恢复 |
| 时间轴分析 | 日期与事项提取要求 | 时间线、无日期事项、来源核对 |
| 风险点分析 | 实际风险点集合、检查要求与顺序 | 按返回情况区分线索、未匹配、资料不足，保留原文依据 |
| 会议纪要分析 | 常规分析要求及议题聚类参数 | 会议时间轴、议题聚类；在本工具继续风险分析和问答 |
| 合同分析 | 合同类别、实际所选规则、补充分析、附件 | 合同信息和规则检查结果；检查事项与原文同屏核验 |
| 招投标分析 | 项目、文件角色、单位、启用环节与规则 | 项目检查、提取信息、核查清单、多文件证据 |
| 待摊费用 | 费用类别、计费约定提取要求 | 先展示计费约定，再在同一任务中填基数继续计算 |
| 工程项目一致性 | 两类识别、比较字段与分数阈值 | 每份台账内部的重复、主子候选及源行 |
| 两表项目关联度 | 两表角色、字段映射、比较规则与上限 | 四类关联结果、二次筛选与恢复、两侧源行 |

提取、核查及汇总可以在工具内按原逻辑衔接，不要求用户手动在多个工具重复传递中间结果。跨工具的配置和业务数据不能未经确认自动互相覆盖。

## 连续核验

合同与招投标从结果进入按需原文/依据双栏，在同一视图保留判断、标准、说明、建议及完整证据；多来源通过来源选择切换。上一条/下一条按当前筛选集合移动，可跨分页。关闭后回原结果、筛选、页码及滚动位置。

信息提取已有双栏核验及前后文件功能，继续复用。会议时间轴、议题聚类、词云等业务成果保持各自形态，不强制改成同一种矩阵。

任一关联来源失去阅读权时，整条结果的正文与原件均不可继续显示；只有原文预览权缺失但仍能阅读分析结果时，可显示获准查看的结果及明确的原件提示。页码和坐标仅使用实际返回，不伪造定位。

## 可选核验意见

核验详情内可折叠记录“已核对 / 存疑”和说明，默认不展开，不增加强制审批，不改变原导出权限和步骤。人工意见与AI输出分开，保存意见不改模型判断、任务配置或原结果。可以单独导出本条核验记录。

浏览器原型按任务、当前核验身份和结果内容指纹隔离记录；数组重排不使旧意见套到新内容，内容变化后不继承原标记。保存、导出前重新校验所有来源权限；新分析不自动继承旧核验意见。

正式系统需使用真实用户、稳定结果ID及服务端意见存储。当前仅浏览器保存；不把原型本地身份当成正式认证，也不把意见保存等同于正式审计审批。
