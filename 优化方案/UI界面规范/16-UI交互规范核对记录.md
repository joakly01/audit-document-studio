# UI交互规范核对记录

日期：2026-10-19。规范版本v1.3；检查对象为当前交互工程及既有规范/增补，不替代正式业务系统验收。

## 核对结论

本轮识别并修正规范内部口径冲突和共用界面偏差。主规范、设计变量、清单、阅读版、PDF与图标登记统一为v1.3，08–15号增补保留追溯并标明主规范优先。原始前端代码及后端接口未修改。

## 差异与修正

| 项目 | 核对发现 | 修正与执行口径 |
| --- | --- | --- |
| 文本检索 | 变量仍列常驻入口 | 资料管理仅更多首项；不重复按钮 |
| 列表排序 | JSON仍指向更多 | 资料列表排序移除；左目录同级拖动保留原权限 |
| 新建文件夹 | 旧说明仍像常驻底部入口 | 目录/空间权限菜单创建，取消左底部及右上常驻新建 |
| 位置与任务入口 | 旧说明保留锁提示/任务中心 | 资料页当前位置不附锁、无任务中心按钮；上传统一叫“上传” |
| 布局 | 独立选择行/标题行的描述残留 | 位置与操作同一行；已选统计在既有分页底栏；无全局面包屑 |
| 模板 | 通用模板术语混淆 | 提取模板只管信息提取字段；其他工具方案和提示词在各工具配置 |
| 字号 | 新资料标识回退为11px，手机主按钮14px | 业务辅助≥14px，主按钮16px且≥36px；工具18px，弹窗20px，密集面板16px |
| 工具操作栏 | 部分手机状态换成多行 | 保留主操作最右；次要控件原节点按实际空间移入更多，缩放恢复，不复制DOM |
| 图标 | 添加与复制都用加号 | 添加用plus，复制新建用copy，更多仍为实心三点 |
| 色彩 | 三种标签及新面板辅助字偏浅 | 共用标签采用规范色；辅助字#596B80；词云保持不同色相并提高文字可读性 |
| 可阅读交付 | 增补已更新，但主文档/PDF未完整合并 | v1.3同步主文档、变量、清单、HTML、PDF及压缩包 |

上述字号是本项目面向审计桌面业务的设计基线，不表述为全国政务屏幕界面的法定统一字号；导出公文按其独立模板管理。

### 2026-10-19 信息提取与模板操作复核

- 信息提取继续按“添加资料—查看原文—调整字段—开始提取—核验结果”组织；左右栏等宽，原件与字段同屏，模板选择不自动执行，另存个人模板保持直接可见。
