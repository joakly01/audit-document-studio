# 已选清单与状态数据补充

> 2026-10-19：有效规则已合并至v1.3主规范。本页保留历史追溯；与主规范有差异时，以用户最新要求和v1.3主规范为准。

2026-10-18，增量规则。

1. 已选文件是独立清单，使用勾选、序号、名称、解析状态、所有者、位置、操作七列；不以窄卡片堆叠长文件名和目录。
2. 主列表已选范围与弹窗待移除勾选分别维护。单项移除、全选/半选、批量移除和清空可操作；批量操作保留确认，取消不丢草稿。移除仅取消选择，不删除原文件，不依赖原文件删除权限。
3. 名称和位置可搜索；搜索不改变清单或隐藏条目的待移除勾选。预览返回保留状态。表格及横向滚动独立，表头、勾选列和操作固定；键盘勾选后保留焦点。
4. 弹窗常态宽1120px、四周留16px，低矮与窄屏仍可操作；正文16px、辅助14px。统计只强调文件数量与解析情况，不冒充工具分析任务进度。
5. 状态验收需覆盖上传中、排队中、识别中、完成、失败及积压，失败细分可重试恢复、空正文、缺原件等真实交互分支；状态切换、筛选、统计和工具接收范围必须一致。

[本轮状态目录、原功能对照与验证](../交互原型/状态资料与已选清单-核对说明.md)

目录区不常驻底部“新建文件夹”按钮；目录省略号菜单保留按权限新建子文件夹，释放目录列表高度。

中间资料操作栏在面包屑前明确标注“当前位置”，不再常驻目录收起图标；窄屏或目录已隐藏时，通过更多展开，保留目录可达性。
