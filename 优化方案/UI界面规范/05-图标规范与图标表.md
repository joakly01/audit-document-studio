# 图标规范与图标表

版本1.3 · 2026-10-19 · [可视化速查](06-图标速查.html) · [机器可读注册表](07-图标注册表.json)

## 1. 样式与尺寸

默认采用同一套线性图标：24×24 画布，通常显示 18–20px，辅助图标可为 16px，线宽约 1.6–1.8px，圆端点、圆连接，颜色使用 currentColor。图标画布与点击区域分别设置，行内操作点击区通常为 30×32px，不能因为图标小就做成难点的小目标。

**更多使用三个实心圆点，拖动排序使用六个实心圆点。** 这两种点阵使用 fill=currentColor、stroke=none；不得使用空心圆圈、字符省略号或近零长度线段凑图。其他图标不因该规则全部改成实心。

## 2. 语义、可发现性与权限

- 同一功能在目录、表格、弹窗和工具内保持相同图形；不同含义不滥用同一个图标。
- 省略号表示当前对象的其他操作，具体内容在菜单中分组表达；低频管理保持轻量，不放大成大管理按钮。
- 六点手柄只用于调整同级先后，不表示跨层级移动。拖动权限沿用原系统：超级文件管理员在公共/个人空间内同级排序；不扩展项目空间未支持的保存接口。
- 所有图标操作有文字标签或可访问名称；仅图标按钮提示对象名称。悬停/焦点有反馈，触屏入口仍可发现。
- 工具图标可采用适度的语义色，状态不能只依赖颜色；不使用表情符号替代业务图标。
- 新功能先查注册表；已有图形语义不合适时再新增登记，写明名称、用途、尺寸、状态和禁用边界。

## 通用分析工作区增补

![清单/词频](assets/icons/list.svg) `list`：词频表、议题清单、事项列表和基础信息表。保留 `menu` 用于导航菜单，`file` 用于原文件对象，不混淆。图标与新增的注册表及SVG资产同步。

“复制新建”使用copy，添加资料使用plus，二者不再共用加号。操作栏的更多使用more（实心三点），配置区的下拉菜单可配down表示展开。
