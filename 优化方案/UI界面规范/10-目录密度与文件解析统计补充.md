# 目录密度与文件解析统计补充

> 2026-10-19：有效规则已合并至v1.3主规范。本页保留历史追溯；与主规范有差异时，以用户最新要求和v1.3主规范为准。

2026-10-18，最新增量优先于既有说明和历史PDF。

1. 选中范围属于资料表格。选中统计在现有表格底栏，右侧工具箱不再重复放置状态卡。
2. 使用完整名称“已选文件”“解析完成”“解析未完成”。禁止单用“完成”“待处理”描述资料解析数量，以免误解为工具分析任务进度。悬停说明明确“文件正文解析状态，不代表工具分析进度”。
3. 解析未完成含未解析、解析中、失败和积压。权限变化独立表示，不能计作解析失败。点击统计可核查全部选中文件，清空选择不会删除文件。
4. 底栏数字18px、标签14px；主控件和正文仍16px。桌面合并到既有分页栏；移动端可紧凑换行，不能越屏遮挡分页。
5. 左目录常态240px，中等窗口上限220px、小屏桌面190px；右侧工具箱260/240/210px。用户自定义目录宽度继续保存；移动端两侧按需展开。
6. 内容按审计业务组织：机构、领域、年度、材料类型，多级目录内允许文件与文件夹混排。同名文件要结合位置区分。增加内容不改变权限、既有编辑或删除记录。
