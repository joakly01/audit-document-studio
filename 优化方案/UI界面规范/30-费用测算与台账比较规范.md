# 费用测算与台账比较规范

更新日期：2026-10-23。适用于待摊费用、工程项目一致性、两表项目关联度；以本次原前端核对为准。

## 共用流程

1. 准备页以“资料 / 分析设置”两栏为主，原文件与解析正文按需打开；不要求先预览才能执行。每个按钮说明实际操作，不以“分析方案”代替提示词或参数。
2. 提示词沿用公共、机构、个人来源与系统默认，阶段之间独立。切换提示词附带字段或规则时先确认；取消不覆盖当前配置。
3. 资料范围、字段映射、预筛与结果评分分开表达。检索、分页和浏览阶段不改变执行范围。
4. 结果主操作统一为“调整后再分析 / 导出”；历史任务配置只读，沿用后进入独立草稿。结果页不再常驻左侧已选资料清单。
5. 保留真实返回的来源行、字段、规则和判断说明；0、false、完整对象和未返回值区别处理。候选、计算结果和模型判断不能直接称为已确认审计发现。
6. 大清单分页、表格独立滚动；主操作、分页与弹窗确认在低高度和手机屏可达。正文和主要控件16px，辅助信息不低于14px。

## 待摊费用

- 分为“提取计费约定 → 填写计费基数并计算”两阶段，第二阶段延续同一任务，不新建重复任务。待填写状态可从任务中心继续。
- 保留原六类费用及两个独立提示词。明确费用类型与合同约定是否匹配，不把演示费率当作通用收费标准。
- 基数单位沿原界面为“元”；后台参数即使命名含 `_wan`，值也不能擅自换算为万元。
- 原逻辑为整个任务一个基数。多份合同参与时明确本基数适用于本任务，逐份显示各自约定和计算结果，不能默用第一份合同的费率套算其他合同。
- 已完成任务冻结本次基数与约定，报告保留来源、公式、输入及结果；调整后再分析生成新记录。

## 工程项目一致性

- 在每份台账内部识别重复项目和主子项目，两个阶段独立配置并共同执行；浏览页签不代表仅执行当前页签。
- 逐份显示表头映射是否就绪及缺少的列。多份文件共用映射，不把不同文件的记录混在一起比较。
- 保留字段、比较方式、预筛、权重、评分说明、最少匹配字段及补充要求。预筛参数与最终0–5评分明确区分。
- 结果保留重复候选、模型识别的主子候选和编码匹配来源。编码匹配不经模型评分，原返回的固定分值须注明其含义，不能称为模型置信度。
- 结果展示字段名来自实际表头或执行快照；详情同时对照两条源记录与实际字段分数，导出保留原始行和完整字段。

## 两表项目关联度

- 两张台账分别指定来源与业务名称，字段表明确“表一列 → 表二列”，支持不同列名，不强制列名相同。
- 保留标准/批量模式、每行/全局候选上限、预筛、权重、最少匹配字段、锁定策略、单项及组合硬规则和补充要求。
- 原判定为完全一致严格大于完全一致阈值、部分一致大于等于部分一致阈值；界面不得把边界条件改为其他比较方式。
- 结果保留完全一致、不完全一致、表一独有、表二独有四类；只有返回明确独有记录时才显示，不能从未返回配对自行推断独有或无关联。
- AI二次筛选针对配对结果，独有记录保留，并提供恢复；当前显示范围与完整原始返回必须清楚区分。源行核验保留两表实际字段，导出不丢原字段及比较说明。
