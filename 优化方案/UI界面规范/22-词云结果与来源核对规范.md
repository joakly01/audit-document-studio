# 词云结果与来源核对

更新日期：2026-10-22。

2026-10-23补充：结果页顶部仅保留“导出”，任务信息、执行配置从任务中心查看，取消结果页的复制新建和本次配置等重复入口。词云视图、词频表、筛选、来源核对及停用词功能按下列规则保留。

词云结果页默认并列高频词概览与词频明细，支持切换到单独词云或词频表。标题展示任务名称、当前统计资料数、匹配词数；显示上限与匹配总数分别表达，避免把前N个词误认为全部结果。

搜索只匹配词语。资料范围、展示前N词与清除筛选放在同一工具栏。词云和明细共享过滤与词频口径，按单份资料筛选时使用该资料词频。老任务缺少分文件词频时明确说明整批口径，不伪造分文件次数。

明细显示词语、出现次数、涉及资料数和“加入停用词”，每页20条，固定分页区。点击词语或资料数可查来源；词云图点击词语使用同一入口。加入停用词只作用于下次分析，不删改本次结果，操作列名称为“下次分析”，成功后显示“下次已停用”。

来源弹窗展示当前范围内的次数、资料数量、文件名、目录、命中片段和核对原文入口。支持按文件或目录搜索，每页10份资料；原文核对关闭后返回原来源弹窗。内容较多时在列表内部滚动。

词云图下载对应当前范围；表格导出分别提供本次全部结果、当前筛选或单文件范围。所有数据导出继续复核权限，保存任务用词快照。

正文16px、辅助14px；小屏可切换视图。1024×480嵌入尺寸保留筛选、结果和分页，不恢复左侧资料清单。
