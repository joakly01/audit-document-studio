# 文档挖掘助手：交互规格与前后端实施清单

V0.1评审稿，2026-10-17。本文是建议设计，不代表接口或页面已经实现。现状依据见 [诊断报告](01-现状诊断与优化建议.md)。

## 1. 统一工作台

准备阶段布局：

```text
资料挖掘 / 信息提取          任务名称（可改）       历史任务  返回资料库
来源：个人空间 / 项目资料     当前执行范围：126份可用文件
┌──────────────────┬───────────────────────────┬─────────────────────┐
│ 本次资料         │ 原文预览                  │ 分析配置            │
│ 添加文件         │ 文件名 / 完整路径         │ 模板：通用基础信息  │
│ 搜索本次资料     │ 页码 / 缩放 / 全屏        │ 适用范围与输出说明  │
│ 目录             │                           │ 字段摘要 / 修改字段 │
│  ├ 文件1         │ 文档内容                  │ 附件处理            │
│  └ 文件2         │                           │ 高级设置（折叠）    │
│ 已排除列表       │                           │                     │
│ 批量管理         │                           │                     │
└──────────────────┴───────────────────────────┴─────────────────────┘
126份可用；2份未就绪 [查看原因]           模板已就绪               [执行]
```

示意数量与实际资料无关。“已加入数”“可执行数”“排除数”分别显示，不混用。已加入总量包含可用和未就绪，移出/排除另列；递归目录去重后的权威计数由后台返回。

建议宽屏左栏260—300px、配置栏320—380px，中间自适应；约1280px以下将配置改抽屉，原文与结果可切换。这是布局起点，需在完整系统的导航下复核。保留宽度拖拽并可恢复默认。

执行中保留任务、资料与配置快照，显示已受理、排队、分析、待人工输入等阶段。已完成部分可查看，用户可回资料库。关闭页面与停止任务是不同动作。没有可靠总量时显示阶段与完成数量，不显示推测进度或剩余时间。

完成阶段布局：

```text
信息提取 · 任务A          完成118 / 失败2 / 跳过6     重试失败   导出
┌──────────────────┬──────────────────────────┬─────────────────────┐
│ 本次资料/状态筛选│ 结果表（主区）           │ 原文证据            │
│ 文件及状态       │ 文件 / 字段 / 提取值     │ 文件名称与路径      │
│ 搜索、定位       │ 出处 / 核验状态          │ 页码及原文高亮      │
│                  │ 点击一项联动原文         │ 无定位说明原因      │
└──────────────────┴──────────────────────────┴─────────────────────┘
查看本次配置（只读）     复制配置新建分析     使用这些资料继续分析
```

结果与专业图表使用主区，证据可折叠，复杂表格可全屏。任务进行中看部分结果需标明尚未完成。修改历史配置产生新执行版本，不覆盖旧结果。

## 2. 文件选择与工作集规则

### 2.1 四种状态各有唯一含义

| 概念 | 行为 | 状态规则 |
| --- | --- | --- |
| 浏览位置 | 点击目录查看其中资料 | 不改变执行范围 |
| 预览焦点 | 点击文件名查看原文 | 不增删资料，不改变执行范围 |
| 本次资料工作集 | 点击“添加文件”加入 | 工作集内可用资料默认参与执行 |
| 批量管理勾选 | 进入“批量管理”勾选 | 仅用于移出/恢复；未移出的资料仍参与执行 |

源资料库中的勾选用于带入工具；进入工具后转成工作集。普通浏览状态隐藏管理复选框。延续现有整份工作集执行机制，同时消除勾选数量与执行数量的误导。

### 2.2 添加文件弹窗

保留目录、文件列表、已选摘要三栏，标题改为“添加文件”。

1. 定位空间/目录，顶部显示路径，显式切换“当前目录/包含子目录”。
2. 勾选直接改变弹窗内暂存选择，去掉“添加到已选择”中间步骤。
3. 表头复选框为“选择当前页（N）”；另设“选择所有页（N）”，说明“当前目录及当前筛选条件下的全部可用文件”。仅看已解析时持续显示筛选标签。
4. 文件夹加入支持“仅当前目录/包含子目录”，右侧显示范围，不能用文件夹数替代文件数。
5. “添加N份文件”一次提交增量，取消不改变原工作集。重复加入按文件身份去重。

切页保留已选。切换筛选后原选择仍保留，显示“另有N份已选不在当前筛选中”；再次“选择所有页”仅新增当前条件匹配范围。提供查看全部已选和清空暂存。默认只展示可选资料时，给出被隐藏的未解析/不适用资料数量及查看入口。

### 2.3 大目录、去重与快照

- 浏览与已选列表分别按需分页/虚拟渲染。所有页选择记录查询范围，由服务端解析，不循环取完全部页模拟全选。
- 目录选集记录稳定ID、递归范围、筛选条件；排除项记录文件ID。路径仅展示，不作为身份。同名不同ID文件不能合并。
- 父目录、子目录、单文件重复加入按文件ID去重，最终数由服务端校验。附件计数与重复处理规则必须明确。
- 初选可显示估算数，提交前进行权威校验。现有目录筛选和排除能力优先复用，但要验证语义。
- 建议提交时固化选集快照，后续目录新增资料不加入运行中的任务。提交前删除、新增、权限变化导致范围改变，展示差异后再确认。
- 计数失败显示“数量待确认，重试”，不能当成0。目录加载失败与空目录分开。

### 2.4 移出、恢复与不支持资料

工作集行操作统一“预览/移出本次分析”，移出后可撤销，也可从已排除列表恢复。父目录中某文件被移出时必须生成排除项，不能只隐藏当前页的行。

未解析、解析失败、格式不适用资料持续显示原因与处理入口。执行前显示“可执行N份，未就绪M份”。允许仅执行可用部分时列出跳过清单；全部不可用则禁用执行并定位问题。原文件删除仅出现在资料管理页，不与移出工作集混用。

## 3. 配置与提示词

### 3.1 先展示业务选择

信息提取首层为模板、输出字段摘要、必要的附件策略。“通用文档基础信息”默认模板加载失败时显示重试或选择其他模板，不能显示为已就绪。字段建议见诊断报告。

高级设置默认折叠：切片长度、重叠长度、执行模式等。用业务语言解释，例如“分段阅读长度”，技术名称放说明中；影响系统资源的配置只给相应角色开放。

本次修改可直接执行，“保存为模板”不作为前置。切换模板影响未保存字段时提供“替换为新模板/保留当前配置”，不得静默丢失。复杂提示词使用宽抽屉或弹窗，不长期挤在窄栏中编辑。

### 3.2 来源、操作与权限

| 来源或场景 | 普通使用者 | 维护规则 |
| --- | --- | --- |
| 系统功能模板，尤其招投标规则 | 选择、查看业务说明；正文可见性由权限决定 | 后台认定的系统维护角色修改原模板 |
| 公共/机构模板 | 按USE使用；可否创建个人副本由能力声明决定 | 按EDIT维护，显示维护机构/人员 |
| 个人模板 | 在有权限的个人空间创建、编辑 | 所有者及受权角色 |
| 会议纪要本次分析要求 | 修改本次要求、恢复模板、另存我的提示词 | 修改场景副本，不改系统底层格式、必需字段与来源约束 |

会议明确要求可修改，但没有定义系统提示词哪些段落可开放。建议场景要求与系统输出约束分层。若当前后台只接受一个完整prompt，先通过受权副本机制实现并校验输出结构，不能只在前端放开文本框。

另存个人：填写名称，选可写个人分类，保存来源模板ID/版本及用途；同名时重命名或有权覆盖。失败保留文本。“本次修改未保存到模板”持续显示。保存个人副本与修改系统原件是不同接口行为。

## 4. 任务状态和恢复

```text
准备中 → 校验中 → 提交中 → 已受理 → 排队/处理中 → 完成
                    │                     ├→ 部分失败
                    │                     ├→ 失败
                    │                     ├→ 待人工输入 → 继续处理
                    │                     └→ 停止中 → 已停止
                    └→ 提交状态待确认 → 查询受理结果 → 已受理/明确未受理
```

连接中断、查询失败属于界面观察状态，不等于后台任务失败。各工具状态通过适配层统一展示，保留专业业务阶段。

| 状态 | 文案与行为 |
| --- | --- |
| 准备不足 | “还有2项配置未完成”，列出具体项并可跳转 |
| 提交中 | 防重复提交，保留资料和配置 |
| 超过等待阈值，无回执 | “正在确认是否已受理”；可查询，不能提示成功或盲目重提 |
| 已受理 | 显示任务编号、范围、进度入口，允许继续其他工作 |
| 处理中 | 业务阶段及服务端计数；部分结果可查看 |
| 部分失败 | 保留成功结果，显示失败原因，按后台支持粒度重试 |
| 查询异常 | 显示最后更新时间、“暂无法获取最新进度”，提供重连 |
| 待人工输入 | 明确需要补什么及单位，补齐后继续 |
| 已停止 | 区分已完成、已停止、未处理，保留策略由后台决定 |

实现时重点复核：

- `batchExecuteTimeoutNav.js`：移除计时器宣布成功；超时后仍接收迟到回执和错误；离开页面后由任务服务接续。
- `useScheduleTaskProgress.js`：当前可因任一结果失败提前返回失败。其他子任务仍执行时不能停止整批反馈，需要明确聚合终态与部分失败契约。
- `useTaskPolling.js`：首次立即轮询后又设置interval，异步interval也有请求重叠可能。改为上一请求完成后安排下一次，终态、卸载、重新启动时清理；属于改造时应验证的实现项。
- `deleteTaskAPI` 共用停止未完成任务与删除历史语义，按钮需随真实状态区分，服务端处理点击后状态变化的竞争情况。
- 简单任务默认一次执行，不强制重复填任务名；复杂大批量任务同页展开范围确认，名称给默认值并可改。

## 5. 结果核验与导出

结果说明源任务、资料范围、模板版本、处理时间、覆盖及失败情况。引用优先使用 `fileId + version + page + anchor/bbox`；坐标单位和页码规则由接口约定。

定位降级：可靠坐标高亮 → 页码定位 → 原文片段及文件链接。没有数据显示“暂无精确页码”，不编造页码，也不把文件链接当精确定位。

信息提取用动态字段表；风险与合同展示疑点、检查项、依据、建议核验动作；会议支持会议/议题双向查看；专业表格保留映射和结果结构。“未发现疑点”“未能提取”“未处理”“证据不足”分开，不能都显示为空。

人工核验若上线，提供未核验/已确认/已排除及备注，后台持久化修订与版本，不能只改显示值。第一批可先做只读核验和出处联动。

导出明确全部结果/当前筛选/已核验范围及数量。若现有接口只能导出全部，只展示“导出全部结果”。异步报告有生成状态、失败重试与过期链接刷新。

## 6. 专业功能差异

| 功能 | 准备阶段 | 关键结果 | 后台待核实 |
| --- | --- | --- | --- |
| 主题归纳 | 自动发现/指定主题；固定事项/临时主题；主题表导入预览及校验 | 基础信息总表、主题与文档对应、来源 | 指定主题载荷、导入与统一表持久化 |
| 通用风险 | 默认模板、可选关注点、自定义关注内容 | 疑点、证据、按资料或关注点筛选 | 无风险树时可否通用执行，各模式语义 |
| 会议纪要 | 基础分析，风险为后续动作 | 时间轴、议题、风险、引用问答 | 修改要求是否进入载荷，问答和任务绑定 |
| 合同 | 类型、检查模板、附件策略 | 规则结果、原文、报告 | 就绪提示与真实必填校验一致性 |
| 招投标 | 项目、招标文件、投标单位归组，按目标选模式 | 项目/单位/规则与证据 | 模式最低资料数、跨文件条件、系统模板权限 |

| 词云 | 停用词、新词、数量 | 词云、词频、来源 | 词对应的文档/片段索引 |

此处规定交互和可核验性，不评价现有法律规则、费用公式或模型结论是否正确。

## 7. 前端实施

沿用Vue、Element Plus和项目样式，在完整 `agent-web` 工程做纵向样板，再抽公共能力，不大范围替换摘录包。

建议逻辑组件边界（新名称，不是现有文件）：

```text
AnalysisWorkbench
  WorkbenchHeader       当前任务、来源与历史
  SelectionWorkspace    本次资料、路径、状态、移出/恢复
  DocumentPreview       复用 FilePreview / PreviewFile
  AnalysisConfigPanel   基础/高级配置 + 专业插槽
  ExecutionStatusBar    受理、进度、错误与继续执行
  ResultWorkspace       专业结果插槽 + EvidencePanel

useAnalysisSession      工作集、草稿、配置快照
useSelectionSet         文件、目录、查询范围、排除项
useAnalysisTask         提交回执、任务状态、恢复
```

不要求一次创建所有组件。预览焦点、管理勾选、执行选集、任务快照分别存储，避免同一个 `selectedFiles` 承担四种含义。真实资料和敏感文本不默认长期存浏览器；恢复优先引用后台任务/草稿ID。

## 8. 前后端能力边界

### 已发现的接口封装，优先复用

| 能力 | 现有接口 | 需确认 |
| --- | --- | --- |
| 文件查询 | `GET /api/v1/file-manager/files` | recursive、筛选、权限、total一致性 |
| 按选集执行 | `POST /api/v1/task/BatchExecuteByFilter` | folders/files/checked_tree/deleted_files权威规则 |
| 任务调度 | `task-CreateSchedules` | selection_sources与批量接口是否等价，不直接混用结构 |
| 状态与结果 | GetTaskSchedules、runtime、GetTaskResultDetail、FolderFilesPage | 终态、部分失败、步骤、大结果分页 |
| 重试/停止 | RetryFailedResults、DeleteTaskSchedules | 重试粒度与条件、停止语义 |
| 模板/提示词 | template系列、`/api/v3/prompts`及权限接口 | 个人空间、默认模板、USE/EDIT与维护权限 |
| 预览与报告 | preview、preview-pdf、导出与报告系列 | 来源定位、下载权限、有效期 |

### 需要确认或补充的契约

以下是概念操作，**不声称已有这些接口或URL**。

1. `resolveSelection`：输入空间、文件ID、目录范围、筛选、排除；返回去重后的有效数量、跳过分类、错误、选集版本/快照ID。成员预览分页；失败不改原选集。
2. `submitAnalysis / lookupSubmission`：输入 `clientRequestId`、选集快照、工具、配置快照；成功返回taskId。同一请求重复提交返回同一任务，超时按请求ID查受理。配置或选集改变才生成新请求ID。
3. 任务状态：阶段、终态标识、总数/完成/失败/跳过、结果版本、待人工输入、更新时间。前端不凭一个子项失败判定全批完成。
4. `getResultEvidence`：文件ID/版本、页码、片段、锚点/坐标、定位质量；缺少坐标可降级，读取再次鉴权。
5. `saveReview`：若支持人工修订，保存结果ID/版本、前后值、状态、备注，处理并发冲突；可后置。
6. 配置能力声明：是否可改本次要求、另存个人、编辑原模板及目标空间。前端据此展示，后台真实校验。

概念模型，需适配已有字段，不可直接当已支持载荷：

```ts
type SelectionDraft = {
  explicitFileIds: string[];
  folders: { folderId: string; scope: 'SELF' | 'SELF_AND_DESC'; filters: object }[];
  queries: { scopeId: string; filters: object }[];
  excludedFileIds: string[];
};
type AnalysisSubmission = {
  clientRequestId: string;
  selectionSnapshotId: string;
  toolKey: string;
  configSnapshot: {
    templateId?: string;
    templateVersion?: string;
    userInstructions?: string;
    parameters: object;
  };
};
```

**前端可先做：**命名、层级、空态、折叠、预览焦点、工作集管理、准确状态反馈、组件整理。

**已有接口需联调：**目录执行、排除、进度、重试、另存模板、历史回显。

**后台需补齐或确认：**查询选集快照、幂等受理查询、统一证据、人工核验修订。不能仅靠前端假进度、浏览器缓存或新增按钮承诺这些能力。

## 9. 验收场景

以下是拟定要求，**不是本轮已执行测试结果**。在完整系统与受控真实资料下验证。

| 场景 | 预期 |
| --- | --- |
| 初次信息提取 | 看懂默认模板、输出字段、添加入口，无须理解提示词和切片 |
| 多页目录 | 当前页/所有页清楚，切页不丢选择，全选不拉取全部内容 |
| 父子目录及重复文件 | 去重正确，同名不同ID保留，摘要与真实执行集合一致 |
| 目录排除一份 | 后台确实排除，撤销重新纳入，原文件未删除 |
| 追加 | 保留工作集和配置，不覆盖旧选择，重复项明确说明 |
| 不适用/未解析 | 有原因及跳过清单，全不可用不能执行 |
| 切换工具 | 资料保留，不适用显式提示，专业配置不串用 |
| 修改模板 | 进入执行快照，切换不静默丢失，普通用户不修改系统原模板 |
| 会议提示词个人复用 | 保存后可重选，来源保留，失败文本不丢 |
| 提交超过等待阈值 | 无虚假成功，可查询，重复请求无第二任务 |
| 关闭后返回 | 已受理任务继续，按ID恢复进度、资料、配置 |
| 一份失败其余进行中 | 正确显示部分失败/仍处理中，不提前宣告全批结束 |
| 来源失效/无坐标 | 说明无法精确定位或版本变化，无伪造证据 |
| 导出 | 范围与选择一致，部分结果标识未完成及失败 |
| 待摊费用补参数 | 单位清楚，缺参不能计算，继续提交不重复执行 |
| 权限变化 | 预检、执行、证据、导出后台校验，不泄漏无权资料 |
| 布局与键盘 | 1366×768、1920×1080主按钮可见，弹窗焦点可达/可返回，状态不只靠颜色 |

规模验证覆盖单文件、多页目录、万级目录成员、大页数PDF、扫描件、混合格式、网络抖动。记录真实加载、提交、恢复耗时，再确定性能目标；不以虚拟列表组件存在作为大规模验收结论。

## 10. 评审决策

1. 是否采用工作集默认全部执行。若要仅勾选执行，所有工具的界面、载荷、历史回显必须同时切换，不混用。
2. 通用模板字段与专业模板维护责任。
3. 会议提示词可修改边界，系统模板维护角色及正文可见性。
4. 机构节点可选、汇总、可写规则，项目/行业权限来源。
5. 后台选集快照、幂等查询、定位数据已有多少能力。
6. 第一批是否含人工修订；建议先完成可读、可定位、可导出，再补修订持久化。

这些决策不妨碍先完成信息提取样板的线框和纯前端交互；涉及权限、执行范围及新增协议的行为，上线前需业务与接口双方确认。
