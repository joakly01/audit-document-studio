# 共用页面与状态设计

本文件定义所有工具共用的操作约定。F表示可通过前端改动实现；R表示需核实或联调已有接口；E表示能力扩展，不作为本轮默认承诺。

## S01 资料主页：保留文件管理器，让入口说清用途

对应：主页面、空间范围选取、文件展示三张截图，`views/file-manager-code/Index.vue`。

**审计任务：**确认正在使用哪个机构/项目/个人空间的资料，找到材料，选择合适工具。

**保留：**左目录、中间文件表、右工具箱、顶部上传与任务中心、分页、权限过滤。

**精修：**

1. 顶部空间选择下方/表头增加固定面包屑，例如“项目空间 / 示例项目 / 2026年度 / 合同资料”。目录名变化后同步更新，不能只靠左侧高亮判断来源。（F）
2. 文件表前的操作条显示“已选12份，其中10份可分析、2份未就绪”。点击数量打开已有已选清单。跨页选择保留并说明“含其他页”。（F/R）
3. 右工具箱仍用原图标和名称，每项补一行业务说明，如“信息提取｜把关键内容整理成表”。鼠标悬停/键盘聚焦再展开适用资料和输出说明，不必新增二级工具首页。（F）
4. 不自动替用户选择工具；未选文件也可打开工具并继续添加。已选文件进入工具时继承，在目标页显示带入了多少、哪些不适用；无效文件不能只闪一个消息后消失。（F）
5. 保留现有分类，不必本轮重配分类字典。在标题有明显不匹配时先改展示名；如“待摊费用”不要继续被解释成招投标环节，具体分组与维护方确认。（F/R）
6. 文件名最多两行，完整名/路径通过悬停或详情获得；“预览”用文字，其余低频操作进入“更多”。原文件删除保留明确确认与真实权限限制。（F）

**首次/异常：**

| 情况 | 页面提示 | 下一步 |
| --- | --- | --- |
| 未选目录 | 从左侧选择资料目录，也可先选择右侧工具 | 不显示“该文件夹暂无文件” |
| 真空目录且可写 | 此目录暂无资料 | 上传文件 / 上传文件夹 |
| 真空目录且只读 | 此目录暂无可查看资料 | 返回上级，不露无权限上传按钮 |
| 搜索无结果 | 未找到符合当前条件的文件 | 清除筛选；保留目录和搜索词 |
| 查询失败 | 资料列表暂未加载成功 | 重试；不以空目录代替错误 |
| 工具箱加载失败 | 工具列表加载失败 | 重试；不回退无权限过滤的工具字典 |

**首用验证：**第一次打开的人能说出当前资料位置，并能仅凭名称+说明区分信息提取、合同分析、会议分析。无需额外“开始使用”引导页。

## S02 空间/机构选择：选择范围，不混入业务目录

保留当前空间弹出树。第一层为公共、项目、个人；公共/项目展开遵循已有机构和项目权限。范围选择只呈现该层该呈现的机构/项目，业务目录在左侧文件树浏览。

- 当前空间与已选机构/项目名称持续显示；重开定位当前项，不自动展开所有机构。
- 目录树的浏览、资料写入权限按后台结果处理，不能因节点可选就允许上传。机构汇总与末级可写的争议作为业务确认项，前端不自行改变。
- 切换资料空间只影响浏览位置；已选清单如果保留跨空间资料，明确显示来源分组。原有不允许跨空间时给具体说明，不静默清空。
- 有未保存工作集修改才提示离开；纯浏览切换不弹确认。

## S03 添加文件弹窗：去掉多余一步，精确解释范围

对应选择文件截图与 `components/common/FileSelectDialog.vue`。保留三栏与分页。

**首屏：**标题“添加文件”；左为位置，中为资料列表，右为本次已选摘要。打开时带入已有工作集，并在弹窗中做暂存副本。

**操作规则：**

| 用户动作 | 界面响应 | 选择结果 |
| --- | --- | --- |
| 点击目录名称 | 浏览本级资料 | 不自动选择目录 |
| 点击“加入本目录” | 显示“仅本级/包含子目录”选项 | 加入明确范围；不靠无文字的加号表达 |
| 勾选文件 | 右侧摘要立即更新 | 不再需要“添加到已选择” |
| 选择当前页 | 勾选当前页可选文件 | 显示本页新增数和总已选数 |
| 选择所有页 | 加入当前范围和筛选下全部匹配资料 | 持续显示范围与数量，不随翻页丢失 |
| 切页/改搜索 | 浏览变化 | 已选保留，提示不在当前结果中的已选数 |
| 取消 | 关闭 | 丢弃此次暂存修改，原工作集不变 |
| 添加N份文件 | 一次确认追加 | 去重后加入，保留已有配置与预览焦点 |

确认数使用有效文件数量，不能“1个目录”显示为“1个文件”。目录计数失败为“数量待确认”，保留重试；不能填0。重复目录/文件选择按真实ID去重。全选实现复用现有目录/筛选载荷；无法表达的跨页搜索范围单独标明限制，禁止偷偷只选当前页。

**高度与可见性：**文件列表使用弹窗剩余高度，替换固定320px造成的大块空白。页脚固定，右侧摘要可独立滚动。目录选项不随行悬停消失，键盘可操作。加载后不要抢走当前搜索输入焦点。

## S04 工具左侧资料与文件夹：统一“参与分析”和“管理勾选”

对应文件夹展示截图、`OcrLeftSidebar.vue`、`OcrFolderPreviewPanel.vue`。

采用现有执行“左侧工作集全部资料”的语义，正面写明：**“列表中的可用资料将参与本次分析”。**

- 左栏标题“本次资料”；紧接“添加文件”，再搜索，再按原路径组织的目录树。
- 点击文件名只预览；展开目录只浏览；普通模式不展示让人误解为执行范围的复选框。
- 点“批量管理”才展示复选框，工具条写“已勾选N项用于移出”。退出管理不改范围。
- 行尾“移出”替换垃圾桶/删除，工具提示“移出本次分析，原文件保留”；一次移出后可撤销。未支持撤销的旧逻辑先用已有恢复机制连接。
- 目录子项保留懒加载或分页；整目录加入不意味着把全部文件内容拉到浏览器。左树每批加载数量可沿用现有实现。
- 中间不再出现“删除勾选文件（前端）”。若短期无法迁完目录列表，可先保留中间目录只读预览：保留查看/分页，移除删除/全选，侧栏提供“管理本目录资料”抽屉复用原列表组件。这样满足职责清楚，又避免重写大树。
- 执行左下仍保留现有位置，旁边显示“执行范围：23份可用；2份未就绪”。未就绪是列表中的状态项，不假装已经参与分析。

资料不足时的空态：“添加需要分析的文件或文件夹，原资料不会被修改。”按钮“添加文件”。已有资料但还没点文件时，中间：“点击左侧文件查看原文，也可直接按当前模板执行。”不提示用户再选一次资料。

## S05 上传与解析：让用户知道何时能分析

复用已有上传弹窗、分片接口、上传会话、文件解析状态；不重做上传服务。

1. 主页“上传”保留文件/文件夹选项，打开后明确目标目录。上传只在资料管理发生，工具的“添加文件”是选择已有资料，避免两个词混用。
2. 每份资料分别显示“正在上传/上传完成，等待解析/正在解析/可分析/解析失败”，进度条只代表正在显示的那个阶段。
3. 上传结束提示“已上传N份，M份可分析”，可返回目录。解析后台继续时不要求页面等着。
4. 失败行保留文件名、失败阶段和“重试”；关闭弹窗后在已有上传记录恢复查看。断点续传是否真的可用以现有服务验证为准。
5. 格式、大小上限从现有规则取得，选择前即显示。不能自行写一个平台没验证的文件大小承诺。

## S06 附件管理：分清资料关系和分析策略

复用 `AttachmentListDialog.vue`、`AttachmentSelectDialog.vue`。标题“某合同的附件（N）”，按文件名、状态、操作列出。

- “添加附件”表示建立与主文件的关系；“移除关联”不是删除附件原件。
- 分析配置中的“将附件与主文件合并分析”用一句解释覆盖范围，显示本次涉及附件数；默认沿用已选模板/已有业务值，不因改版强行改变。
- 主文件缺少附件、附件未解析时持续提示，不把“附件0份”解释为“合同无附件”。
- 执行摘要说明“主文件N份，合并附件M份”；后台若把附件单列结果，前端照实呈现，不能重复计算完成数量。

## S07 模板/提示词：让用户先理解检查什么

保留现有模板下拉与保存接口。下拉选项显示名称、适用资料、来源；如果没有额外元数据，就先整理名称和现有描述，不虚构作者与维护时间。

一级界面：模板、字段/检查项摘要、可选补充说明。二级抽屉：完整提示词、技术参数、原模板信息。默认只自动选服务端标记的默认项；没有默认时明确要求选择，不随意选列表第一项冒充推荐。

编辑器区分“应用到本次分析”“另存为我的模板/提示词”“修改原模板”。普通用户不出现无权限的修改原模板操作。会议纪要需要本次修改及个人复用；招投标系统模板原件仍按权限维护，但本次分析提示词可编辑（原代码promptOverride已支持，本轮纠正此前限制）。恢复默认仅还原当前编辑内容，有未保存改动时再确认。

保存失败保留文本；切换文件不丢配置；切模板有字段变化时展示将替换的内容。运行后配置只读，重新配置通过复制新建，而不是让历史结果看起来采用了新模板。

## S08 执行：主操作只有一个含义

多数工具主按钮“执行”；费用的阶段按钮和会议风险分析按所在任务语义明确命名。主按钮附近解释缺什么，不能只有灰按钮。

| 状态 | 固定区域展示 | 主操作 |
| --- | --- | --- |
| 无资料 | 请添加需要分析的资料 | 添加文件 |
| 配置不完整 | 还需选择模板/对应2个字段 | 定位到缺失项；执行不可用 |
| 可以执行 | 本次将分析N份资料，采用某模板 | 执行 |
| 提交中 | 正在提交，保留资料与配置 | 按钮加载、防重复 |
| 无回执、等待较久 | 正在确认提交结果 | 不报成功；可查看任务中心确认，避免再次盲提 |
| 有回执 | 任务已提交；某阶段；可离开 | 查看进度，不强制切走 |
| 状态获取失败 | 暂无法获取最新进度；最后更新于… | 刷新，不宣告后台失败 |
| 部分失败 | 成功N份、失败M份，成功结果可用 | 查看失败，接口支持时重试失败 |
| 已完成 | 结果已生成；覆盖N份资料 | 查看结果/导出 |

当前 `batchExecuteTimeoutNav.js` 超时宣布成功必须修正，这是前端反馈正确性问题。先保留迟到响应处理并显示未知状态；服务端按请求ID查询与幂等属于增强，不能靠前端定时器模拟。

## S09 结果阅读：既能扫读，也能核验

- 完成时切到已有结果Tab；不要抢夺正在进行的原文阅读焦点，用户停留原文时用“结果已更新，查看结果”提示。
- 默认显示范围、结果数量、错误数量和当前文件/当前任务。长解释最多2—3行，详情抽屉展示全文；导出保留完整内容。
- “查看原文”只用真实文件/页码信息；没有坐标不展示伪高亮。真实未提及、未提取成功、空字符串、未执行不一概转换为“未发现问题”。
- 结果筛选仅影响查看，配置影响重新执行，二者分区。筛选无命中提供“清除筛选”，不诱导重新分析。
- 当前文件导出与任务全部导出命名不同。保留现有格式，不把只支持全文报告的工具画成支持任意筛选导出。
- 每个工具无需新增“人工确认”按钮；没有持久化能力时不展示看似已保存的核验状态。

## S10 任务中心与历史：能找回、能继续

复用 `views/ocr-task-center/Index.vue` 及详情组件，无截图，以下依据源码。

首屏保留状态、工具、任务名搜索，默认显示有权查看的现有任务范围，按现有时间字段呈现；不杜撰“我的”过滤能力。列顺序建议：任务名、工具、范围、阶段/进度、创建时间、操作。细日志、长备注和调用参数进详情，减少360—400px进度列占宽。

行主操作按状态变化：运行中“查看进度”；完成“查看结果”；部分失败“查看结果”，旁边“失败N”；待填基数“继续填写”；未知态“刷新”。停止任务和删除记录分别命名，不能共用“删除”使用户误以为能撤销后台计算。

任务详情默认业务结果，保留“处理记录”“本次配置”“资料范围”次入口。返回列表保留筛选与页码。合并导出仅显示已有支持的同类任务条件；不符合条件的行明确原因，不让用户勾选后才得到泛化报错。

## 通用视觉与手感规格

- 不换现有蓝色品牌和图标体系。每个操作区一个主要蓝色按钮，查看详情、任务中心、导出按层级处理；绿色/红色用于状态，不给普通导出按钮制造多套强调色。
- 桌面正文以14px起，关键操作32—36px高；根据现有系统整体密度校准。长文件名保留可辨认部分，不能只看到前几个相同字符。
- 只在内容改变的面板加载，不用全页遮罩阻止用户看已有结果；提交按钮单独锁定。
- Tab切换保留滚动位置、筛选和当前文件。结果刷新不跳回第一行。预览切换用最新请求结果，旧请求迟到不能覆盖新文件。
- 弹窗可键盘操作；关闭后焦点回发起按钮；ESC只关闭最上层；仅未保存的重要编辑需要离开确认。
- 删除原件、覆盖模板需确认；移出分析用撤销；普通切页、预览、筛选不增加确认。
- “一眼会用”的评审方式是让陌生使用者指出输入、主按钮、输出位置，再完成任务；不是堆更多说明文字。
